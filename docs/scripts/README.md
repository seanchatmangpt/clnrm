# Script Documentation

Documentation for automation scripts and utilities.

## Available Scripts

- [Logging Library](logging-library.md) - Logging utilities and helpers

## Script Categories

Scripts are organized in `/scripts/` directory:

### Validation Scripts
- `validation_pipeline.sh` - Complete validation pipeline
- `comprehensive_weaver_validation.sh` - Weaver validation suite

### Docker Scripts
- `docker_startup.sh` - Cross-platform Docker startup
- `docker_health_check.sh` - Docker health verification

### OTLP Scripts
- `otlp_config.sh` - OTLP environment configuration
- `weaver_startup.sh` - Weaver process management
