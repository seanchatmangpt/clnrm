## Diataxis Framework

clnrm documentation uses the [Diataxis framework](https://diataxis.fr/) for clear organization:

```
            PROCEDURAL  ←→  CONCEPTUAL
                ↕                ↕
SPECIFIC   [Tutorials]    [How-To]
                ↕                ↕
GENERAL    [Reference]   [Explanation]
```

Each type has a specific purpose and audience:
- **Tutorials** — Learning-oriented, step-by-step
- **How-To** — Task-oriented, practical solutions
- **Reference** — Information-oriented, lookup
- **Explanation** — Understanding-oriented, concepts
