## ❌ Known Issues & Limitations

### 1. Weaver Live Validation Fails (CRITICAL)
**Issue**: Weaver receives zero telemetry samples during test runs
**Error**: `ValidationError: Weaver validation failed: zero telemetry samples received`

**Root Cause**: OTEL exporter configuration issue - telemetry not reaching Weaver's OTLP endpoint (4317)

**Impact**: Cannot validate runtime behavior against Weaver schemas (false negative)

**Workaround**: Run without Weaver validation (tests still pass)

**Status**: ❌ BLOCKS PRODUCTION (violates "Weaver is source of truth" principle)

### 2. Container Pool Not Validated
**Claim**: v1.4.0 promises 80% faster startup via container pooling
**Reality**: Cannot validate with Weaver due to issue #1
**Status**: ⚠️ UNVALIDATED CLAIM

### 3. Registry Path Hardcoded Wrong
**Issue**: Default registry path `/Users/sac/clnrm/target/share/clnrm/registry` doesn't exist
**Workaround**: Set `CLNRM_REGISTRY_PATH=registry` environment variable
**Status**: ⚠️ UX ISSUE (not blocking)

### Critical Blocker

**The False Positive Paradox**: clnrm exists to eliminate false positives in testing. We CANNOT ship clnrm with a false positive validation system.

**Current State**: Tests pass, but Weaver validation fails (zero samples). This is a false negative that indicates OTEL configuration issue.

**Required for Production**: Fix OTEL export so Weaver receives telemetry and can validate runtime behavior.
