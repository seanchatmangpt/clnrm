## Week 1-2: Immediate Wins

### 1. Weaver Checker - Policy Enforcement (3 days)

**Impact:** Prevent schema violations before commit
**Effort:** Low (3 days)
**ROI:** Very High

#### Setup

```bash
# Create policies directory
mkdir -p policies/clnrm

# Create first policy
cat > policies/clnrm/no_deprecated_stable.rego << 'EOF'
package before_resolution

deny[violation] {
    group := input.groups[_]
    attr := group.attributes[_]
    attr.stability != "deprecated"
    attr.deprecated

    violation := {
        "id": "attr_stability_deprecated",
        "type": "semconv_attribute",
        "category": "attribute",
        "group": group.id,
        "attr": attr.id,
        "message": "Attribute marked deprecated but stability is not 'deprecated'"
    }
}
EOF

# Add pre-commit hook
cat > .git/hooks/pre-commit << 'EOF'
#!/bin/bash
weaver registry check --registry registry/ --policies policies/clnrm/
EOF
chmod +x .git/hooks/pre-commit
```

**Result:** Schema violations caught in pre-commit hook

### 2. Weaver Emit - Test Fixtures (2 days)

**Impact:** Automated test data generation
**Effort:** Very Low (2 days)
**ROI:** High

#### Setup

```bash
# Generate test fixtures
weaver registry emit \
    --registry registry/ \
    --format json \
    --output tests/fixtures/ \
    --count 10

# Use in tests
cat > tests/integration/fixture_tests.rs << 'EOF'
use clnrm_core::testing::fixtures::load_spans;

#[test]
fn test_generated_fixtures_pass_validation() {
    let spans = load_spans("container_lifecycle");

    for span in spans {
        emit_span(span);
    }

    // Weaver validates all fixtures
    let report = weaver_report();
    assert_eq!(report.violations, 0);
}
EOF
```

**Result:** Zero manual test fixture maintenance

## Week 3-5: High-Value Code Generation

### 3. Weaver Forge - Type-Safe Builders (2 weeks)

**Impact:** Compile-time telemetry validation
**Effort:** Medium (2 weeks)
**ROI:** Highest

#### Setup

```bash
# Create templates directory
mkdir -p templates/registry/rust

# Create builder template
cat > templates/registry/rust/span_builder.rs.j2 << 'EOF'
// Auto-generated by Weaver Forge - DO NOT EDIT

{%- for group in ctx.groups | selectattr("type", "equalto", "span") %}
pub struct {{ group.id | pascal_case }}Builder {
    {%- for attr in group.attributes | required %}
    {{ attr.id | snake_case }}: Option<{{ attr.type | map_text("rust_types") }}>,
    {%- endfor %}
}

impl {{ group.id | pascal_case }}Builder {
    {%- for attr in group.attributes %}
    pub fn {{ attr.id | snake_case }}(mut self, value: {{ attr.type | map_text("rust_types") }}) -> Self {
        self.{{ attr.id | snake_case }} = Some(value);
        self
    }
    {%- endfor %}

    pub fn build(self) -> Result<Span, ValidationError> {
        {%- for attr in group.attributes | required %}
        let {{ attr.id | snake_case }} = self.{{ attr.id | snake_case }}
            .ok_or_else(|| ValidationError::MissingRequired("{{ attr.id }}"))?;
        {%- endfor %}

        Ok(Span::new("{{ group.id }}", vec![
            {%- for attr in group.attributes | required %}
            KeyValue::new("{{ attr.id }}", {{ attr.id | snake_case }}),
            {%- endfor %}
        ]))
    }
}
{% endfor %}
EOF

# Create config
cat > templates/registry/rust/weaver.yaml << 'EOF'
text_maps:
  rust_types:
    int: i64
    double: f64
    boolean: bool
    string: String
    string[]: Vec<String>

templates:
  - template: "span_builder.rs.j2"
    filter: semconv_grouped_attributes
    application_mode: single
    file_name: "generated/span_builders.rs"
EOF

# Generate code
weaver registry generate rust --registry registry/ --templates templates/

# Add to build.rs
cat >> build.rs << 'EOF'
fn main() {
    // Regenerate on schema change
    println!("cargo:rerun-if-changed=registry/");

    std::process::Command::new("weaver")
        .args(&["registry", "generate", "rust"])
        .status()
        .expect("Failed to generate telemetry code");
}
EOF
```

**Result:**
- Zero manual telemetry code
- Compile errors for missing attributes
- Impossible to emit invalid telemetry

## Week 6: Polish

### 4. Weaver Diff - Evolution Tracking (3 days)

**Impact:** Automated breaking change detection
**Effort:** Very Low (3 days)
**ROI:** Medium

#### Setup

```bash
# Add to CI/CD
cat > .github/workflows/schema-diff.yml << 'EOF'
name: Schema Evolution

on:
  pull_request:
    paths:
      - 'registry/**'

jobs:
  check-breaking-changes:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0

      - name: Check for breaking changes
        run: |
          git fetch origin main

          weaver registry diff \
            --old origin/main:registry \
            --new registry \
            --format json \
            --output schema-diff.json

          BREAKING=$(jq '.breaking_changes | length' schema-diff.json)
          if [ "$BREAKING" -gt 0 ]; then
            echo "::error::Breaking schema changes detected"
            exit 1
          fi
EOF
```

**Result:** Breaking changes caught in CI/CD
