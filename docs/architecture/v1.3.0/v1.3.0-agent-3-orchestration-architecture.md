# Live-Check Orchestration System Architecture
## clnrm v1.3.0

**Author:** System Architect Agent
**Date:** 2025-10-31
**Status:** Architecture Design (v1.3.0)
**Document Type:** Technical Architecture Specification

## Executive Summary

This document defines the architecture for the live-check orchestration system in clnrm v1.3.0. The orchestration system coordinates the lifecycle of Weaver validation with test execution, making Weaver the single source of truth for telemetry correctness. The architecture leverages existing type-safe patterns from `WeaverController<State>` and extends them into a comprehensive orchestration framework.

**Key Design Principles:**
1. **Type-Safe State Machines** - Compile-time enforcement of correct usage
2. **Graceful Degradation** - Fallback to registry check if live-check fails
3. **Zero-Configuration** - Sensible defaults with optional overrides
4. **Fail-Fast Validation** - Immediate feedback on telemetry violations
5. **Production-Ready** - Robust error handling and resource cleanup

## 2. Core Components

### 2.1 LiveCheckOrchestrator<State>

**Purpose:** Type-safe orchestration of Weaver lifecycle with compile-time state enforcement.

**Design Pattern:** State Machine (compile-time enforced via type system)

**States:**
- `Uninitialized` - Created but Weaver not started
- `WeaverRunning` - Weaver process active and coordinated
- `Completed` - Weaver stopped, report available

**Type Signature:**

```rust
pub struct LiveCheckOrchestrator<State = Uninitialized> {
    config: WeaverConfig,
    weaver_manager: WeaverProcessManager,
    otlp_config: OTLPExporterConfig,
    report_parser: ConformanceReportParser,
    state: PhantomData<State>,
}

// State markers
pub struct Uninitialized;
pub struct WeaverRunning;
pub struct Completed;
```

**API Surface:**

```rust
impl LiveCheckOrchestrator<Uninitialized> {
    /// Create new orchestrator from TOML config
    pub fn from_toml_config(
        weaver_config: config::weaver::WeaverConfig
    ) -> Result<Self>;

    /// Start Weaver and transition to Running state
    pub fn start_weaver(self) -> Result<LiveCheckOrchestrator<WeaverRunning>>;
}

impl LiveCheckOrchestrator<WeaverRunning> {
    /// Get coordination metadata for OTEL initialization
    pub fn coordination(&self) -> &WeaverCoordination;

    /// Get OTLP endpoint for exporter configuration
    pub fn otlp_endpoint(&self) -> String;

    /// Check if validation is currently passing (streaming mode)
    pub fn is_passing(&self) -> bool;

    /// Stop Weaver and get validation report
    pub fn stop_and_validate(self) -> Result<LiveCheckOrchestrator<Completed>>;
}

impl LiveCheckOrchestrator<Completed> {
    /// Get final validation report
    pub fn report(&self) -> &ValidationReport;

    /// Consume orchestrator and return report
    pub fn into_report(self) -> ValidationReport;

    /// Check if validation passed
    pub fn passed(&self) -> bool;

    /// Get human-readable summary
    pub fn summary(&self) -> String;
}
```

**Failure Recovery:**

```rust
impl LiveCheckOrchestrator<Uninitialized> {
    /// Try to start Weaver, fallback to registry check if fails
    pub fn start_with_fallback(
        self
    ) -> Result<OrchestrationMode> {
        match self.start_weaver() {
            Ok(running) => Ok(OrchestrationMode::LiveCheck(running)),
            Err(e) => {
                warn!("Live-check failed to start: {}", e);
                warn!("Falling back to registry check");

                let registry_path = self.config.registry_path.clone();
                Ok(OrchestrationMode::RegistryCheckOnly {
                    registry_path,
                    reason: format!("{}", e)
                })
            }
        }
    }
}

pub enum OrchestrationMode {
    /// Full live validation with running Weaver
    LiveCheck(LiveCheckOrchestrator<WeaverRunning>),
    /// Fallback: static registry check only
    RegistryCheckOnly {
        registry_path: PathBuf,
        reason: String,
    },
}
```

**Why Type-Safe States:**
1. **Prevents incorrect usage** - Can't call `stop()` on unstarted orchestrator
2. **Compile-time guarantees** - No runtime checks for state validity
3. **Clear ownership** - State transitions consume and return new types
4. **Self-documenting** - Type signatures show valid state transitions

### 2.2 WeaverProcessManager

**Purpose:** Low-level process lifecycle and health management for Weaver.

**Responsibilities:**
1. Port discovery and allocation
2. Process spawning and monitoring
3. Health checking and readiness detection
4. Graceful shutdown and cleanup

**Type Signature:**

```rust
pub struct WeaverProcessManager {
    /// Configuration
    config: WeaverConfig,
    /// Child process handle
    process: Option<Child>,
    /// Discovered ports
    ports: Option<DiscoveredPorts>,
    /// Monitor thread for streaming output
    monitor: Option<thread::JoinHandle<()>>,
    /// Violation flag (shared with monitor)
    violations: Arc<AtomicBool>,
}

#[derive(Debug, Clone)]
pub struct DiscoveredPorts {
    pub otlp_grpc: u16,
    pub admin: u16,
}
```

**Port Discovery Strategy:**

```rust
impl WeaverProcessManager {
    /// Find available ports with multi-tier fallback
    fn discover_ports(&self) -> Result<DiscoveredPorts> {
        // Tier 1: Standard OTLP gRPC range
        let otlp = Self::find_port_in_range(4317, 4327)
            // Tier 2: Extended fallback range
            .or_else(|| Self::find_port_in_range(5317, 5327))
            .ok_or_else(|| CleanroomError::network_error(
                "No available OTLP ports in ranges 4317-4327, 5317-5327"
            ))?;

        // Tier 1: Standard admin range
        let admin = Self::find_port_in_range(8080, 8090)
            // Tier 2: Extended fallback range
            .or_else(|| Self::find_port_in_range(9080, 9090))
            .ok_or_else(|| CleanroomError::network_error(
                "No available admin ports in ranges 8080-8090, 9080-9090"
            ))?;

        // Ensure ports don't conflict
        if otlp == admin {
            return Err(CleanroomError::network_error(
                "OTLP and admin ports must be different"
            ));
        }

        Ok(DiscoveredPorts {
            otlp_grpc: otlp,
            admin,
        })
    }

    fn find_port_in_range(start: u16, end: u16) -> Option<u16> {
        (start..=end).find(|&port| {
            TcpListener::bind(("127.0.0.1", port)).is_ok()
        })
    }
}
```

**Process Lifecycle:**

```rust
impl WeaverProcessManager {
    /// Start Weaver process
    pub fn start(&mut self) -> Result<WeaverCoordination> {
        // 1. Cleanup orphaned processes
        Self::cleanup_orphans()?;

        // 2. Discover available ports
        let ports = self.discover_ports()?;
        self.ports = Some(ports.clone());

        // 3. Build Weaver command
        let mut cmd = Command::new("weaver");
        cmd.args([
            "registry", "live-check",
            "--registry", &self.config.registry_path.display().to_string(),
            "--otlp-grpc-port", &ports.otlp_grpc.to_string(),
            "--admin-port", &ports.admin.to_string(),
            "--output", &self.config.output_dir.display().to_string(),
            "--format", "json",
        ]);

        if !self.config.stream {
            cmd.arg("--no-stream");
        }

        // 4. Spawn process with piped I/O
        let mut child = cmd
            .stdout(Stdio::piped())
            .stderr(Stdio::piped())
            .spawn()
            .map_err(|e| CleanroomError::internal_error(
                format!("Failed to start Weaver (is it installed?): {}", e)
            ))?;

        let pid = child.id();

        // 5. Start monitoring thread (if streaming enabled)
        let monitor = if self.config.stream {
            Some(self.spawn_monitor_thread(&mut child)?)
        } else {
            None
        };

        // 6. Wait for readiness
        Self::wait_for_ready(&mut child, Duration::from_secs(10))?;

        // 7. Store state
        self.process = Some(child);
        self.monitor = monitor;

        // 8. Return coordination
        Ok(WeaverCoordination {
            weaver_pid: pid,
            otlp_grpc_port: ports.otlp_grpc,
            admin_port: ports.admin,
            ready_at: Instant::now(),
        })
    }

    /// Stop Weaver gracefully
    pub fn stop(&mut self) -> Result<()> {
        let mut process = self.process.take()
            .ok_or_else(|| CleanroomError::internal_error(
                "Cannot stop: Weaver not running"
            ))?;

        // Graceful shutdown via SIGHUP
        #[cfg(unix)]
        {
            use nix::sys::signal::{kill, Signal};
            use nix::unistd::Pid;

            let pid = Pid::from_raw(process.id() as i32);
            kill(pid, Signal::SIGHUP)
                .map_err(|e| CleanroomError::internal_error(
                    format!("Failed to send SIGHUP: {}", e)
                ))?;
        }

        // Wait for exit with timeout
        Self::wait_with_timeout(&mut process, Duration::from_secs(10))?;

        // Join monitor thread
        if let Some(monitor) = self.monitor.take() {
            let _ = monitor.join();
        }

        Ok(())
    }

    /// Check if validation is passing (streaming mode)
    pub fn is_passing(&self) -> bool {
        !self.violations.load(Ordering::Relaxed)
    }
}
```

```rust
impl WeaverProcessManager {
    /// Wait for Weaver to become ready
    fn wait_for_ready(process: &mut Child, timeout: Duration) -> Result<()> {
        let start = Instant::now();

        // Simple strategy: Wait 1 second, check process didn't exit
        thread::sleep(Duration::from_millis(1000));

        match process.try_wait() {
            Ok(Some(status)) => Err(CleanroomError::internal_error(
                format!("Weaver exited prematurely: {}", status)
            )),
            Ok(None) => {
                info!("Weaver ready (elapsed: {}ms)", start.elapsed().as_millis());
                Ok(())
            }
            Err(e) => Err(CleanroomError::internal_error(
                format!("Failed to check Weaver status: {}", e)
```

**Cleanup and Recovery:**

```rust
impl WeaverProcessManager {
    /// Kill orphaned Weaver processes
    fn cleanup_orphans() -> Result<()> {
        debug!("Cleaning up orphaned Weaver processes");

        #[cfg(unix)]
        {
            let _ = Command::new("pkill")
                .args(["-9", "-f", "weaver registry live-check"])
                .output();
            thread::sleep(Duration::from_millis(500));
        }

        #[cfg(not(unix))]
        {
            let _ = Command::new("taskkill")
                .args(&["/F", "/IM", "weaver.exe"])
                .output();
            thread::sleep(Duration::from_millis(500));
        }

        Ok(())
    }

    /// Wait for process exit with timeout
    fn wait_with_timeout(
        process: &mut Child,
        timeout: Duration
    ) -> Result<std::process::Output> {
        let start = Instant::now();

        loop {
            match process.try_wait() {
                Ok(Some(status)) => {
                    // Process exited, collect output
                    let mut stdout = Vec::new();
                    let mut stderr = Vec::new();

                    if let Some(mut out) = process.stdout.take() {
                        use std::io::Read;
                        let _ = out.read_to_end(&mut stdout);
                    }
                    if let Some(mut err) = process.stderr.take() {
                        use std::io::Read;
                        let _ = err.read_to_end(&mut stderr);
                    }

                    return Ok(std::process::Output {
                        status,
                        stdout,
                        stderr,
                    });
                }
                Ok(None) => {
                    // Still running
                    if start.elapsed() > timeout {
                        warn!("Weaver did not stop gracefully, killing");
                        let _ = process.kill();
                        return Err(CleanroomError::timeout_error(
                            "Weaver did not stop within timeout"
                        ));
                    }
                    thread::sleep(Duration::from_millis(100));
                }
                Err(e) => {
                    return Err(CleanroomError::internal_error(
                        format!("Failed to check process status: {}", e)
                    ));
                }
            }
        }
    }
}
```

### 2.3 OTLPExporterConfig

**Purpose:** Dynamic OTLP endpoint configuration based on Weaver coordination.

**Responsibilities:**
1. Generate OTLP endpoint from coordination metadata
2. Configure protocol (gRPC preferred, HTTP fallback)
3. Validate connectivity (optional)
4. Provide initialization helpers for telemetry module

**Type Signature:**

```rust
pub struct OTLPExporterConfig {
    /// Base configuration
    base_config: telemetry::config::OtelConfig,
    /// Dynamic endpoint (set after coordination)
    endpoint: Option<String>,
    /// Preferred protocol
    protocol: OTLPProtocol,
}

#[derive(Debug, Clone, PartialEq)]
pub enum OTLPProtocol {
    Grpc,
    Http,
}
```

**API Surface:**

```rust
impl OTLPExporterConfig {
    /// Create from TOML OTEL config
    pub fn from_toml_config(
        otel_config: Option<config::otel::OtelConfig>
    ) -> Self {
        Self {
            base_config: otel_config.unwrap_or_default(),
            endpoint: None,
            protocol: OTLPProtocol::Grpc, // Default to gRPC
        }
    }

    /// Configure endpoint from Weaver coordination
    pub fn configure_from_coordination(
        &mut self,
        coordination: &WeaverCoordination
    ) {
        // Use gRPC port from coordination
        self.endpoint = Some(format!(
            "http://127.0.0.1:{}",
            coordination.otlp_grpc_port
        ));

        info!("OTLP endpoint configured: {}", self.endpoint.as_ref().unwrap());
    }

    /// Get configured endpoint
    pub fn endpoint(&self) -> Result<&str> {
        self.endpoint.as_deref()
            .ok_or_else(|| CleanroomError::configuration_error(
                "OTLP endpoint not configured (call configure_from_coordination first)"
            ))
    }

    /// Validate connectivity to endpoint (optional sanity check)
    pub fn validate_connectivity(&self) -> Result<()> {
        let endpoint = self.endpoint()?;

        // Try to connect to OTLP endpoint
        // This is optional and can be skipped for performance
        debug!("Validating OTLP connectivity to {}", endpoint);

        // For gRPC, we'd need tonic client
        // For now, just check port is listening
        let port = endpoint
            .split(':')
            .last()
            .and_then(|s| s.parse::<u16>().ok())
            .ok_or_else(|| CleanroomError::configuration_error(
                "Invalid OTLP endpoint format"
            ))?;

        TcpListener::bind(("127.0.0.1", port))
            .map_err(|_| CleanroomError::network_error(
                format!("OTLP port {} is not listening", port)
            ))?;

        Ok(())
    }

    /// Build OpenTelemetry SDK configuration
    pub fn to_otel_sdk_config(&self) -> Result<telemetry::config::OtelConfig> {
        let mut config = self.base_config.clone();

        // Override endpoint with coordinated value
        if let Some(endpoint) = &self.endpoint {
            // Update exporter configuration
            match self.protocol {
                OTLPProtocol::Grpc => {
                    config.export_config = Some(telemetry::config::ExportConfig::OtlpGrpc {
                        endpoint: endpoint.clone(),
                    });
                }
                OTLPProtocol::Http => {
                    config.export_config = Some(telemetry::config::ExportConfig::OtlpHttp {
                        endpoint: endpoint.clone(),
                    });
                }
            }
        }

        Ok(config)
    }
}
```

### 2.4 ConformanceReportParser

**Purpose:** Parse and interpret Weaver's JSON validation reports.

**Responsibilities:**
1. Parse `validation_report.json` from Weaver output
2. Aggregate violations, improvements, information
3. Calculate registry coverage percentage
4. Provide human-readable summaries

**Type Signature:**

```rust
pub struct ConformanceReportParser {
    /// Output directory where report is written
    output_dir: PathBuf,
}
```

**Report Structure (from Weaver):**

```json
{
  "status": "success" | "failure",
  "violations": 0,
  "improvements": 5,
  "information": 10,
  "registry_coverage": 0.85,
  "sample_count": 1234,
  "details": [
    {
      "level": "violation" | "improvement" | "information",
      "metric_name": "clnrm.test.duration",
      "span_name": "test.execution",
      "message": "Missing required attribute 'test.name'",
      "registry_path": "registry/clnrm/test.yaml"
    }
  ]
}
```

**API Surface:**

```rust
impl ConformanceReportParser {
    pub fn new(output_dir: PathBuf) -> Self {
        Self { output_dir }
    }

    /// Parse validation report from disk
    pub fn parse_report(&self) -> Result<ValidationReport> {
        let report_path = self.output_dir.join("validation_report.json");

        if !report_path.exists() {
            return Err(CleanroomError::io_error(
                format!("Validation report not found: {}", report_path.display())
            ));
        }

        let json = std::fs::read_to_string(&report_path)
            .map_err(|e| CleanroomError::io_error(
                format!("Failed to read validation report: {}", e)
            ))?;

        let mut report: ValidationReport = serde_json::from_str(&json)
            .map_err(|e| CleanroomError::serialization_error(
                format!("Failed to parse validation report: {}", e)
            ))?;

        // CRITICAL: Zero samples = no validation occurred
        if report.sample_count == 0 {
            error!("CRITICAL: Weaver received ZERO telemetry samples!");
            report.status = ValidationStatus::Failure;
            report.violations += 1; // Count zero samples as a violation
        }

        Ok(report)
    }

    /// Generate human-readable summary
    pub fn generate_summary(report: &ValidationReport) -> String {
        let mut summary = String::new();

        summary.push_str(&format!("Weaver Validation Report\n"));
        summary.push_str(&format!("========================\n\n"));
        summary.push_str(&format!("Status: {:?}\n", report.status));
        summary.push_str(&format!("Samples Received: {}\n", report.sample_count));
        summary.push_str(&format!("Violations: {}\n", report.violations));
        summary.push_str(&format!("Improvements: {}\n", report.improvements));
        summary.push_str(&format!("Information: {}\n", report.information));
        summary.push_str(&format!("Registry Coverage: {:.1}%\n\n",
            report.registry_coverage * 100.0));

        if report.violations > 0 {
            summary.push_str("VIOLATIONS:\n");
            for detail in report.details.iter().filter(|d| d.level == "violation") {
                summary.push_str(&format!("  - {}: {}\n",
                    detail.metric_name.as_deref().or(detail.span_name.as_deref()).unwrap_or("unknown"),
                    detail.message
                ));
            }
            summary.push_str("\n");
        }

        if report.sample_count == 0 {
            summary.push_str("ERROR: No telemetry samples received!\n");
            summary.push_str("Possible causes:\n");
            summary.push_str("  - OTLP exporter not configured\n");
            summary.push_str("  - Network connectivity issues\n");
            summary.push_str("  - Weaver not listening on expected port\n");
        }

        summary
    }

    /// Check if report indicates passing validation
    pub fn is_passing(report: &ValidationReport) -> bool {
        report.status == ValidationStatus::Success
            && report.violations == 0
            && report.sample_count > 0
    }
}
```

**Error Handling:**


```
                                  │
                                  ▼
                  ┌───────────────────────────┐
                  │  Start Failed?            │
                  └───┬──────────────────┬────┘
                      │ YES              │ NO
                      │                  │
        ┌─────────────▼──────┐          ▼
        │ OrchestrationMode  │   ┌──────────────┐
        │ ::RegistryCheckOnly│   │WeaverRunning │
        │                    │   │              │
        │ (fallback mode)    │   │ - coordinated│
        └────────────────────┘   │ - OTLP ready │
                                 │ - monitoring │
                                 └──────┬───────┘
                                        │
                          stop_and_     │
                          validate()    │
                                        │
                                        ▼
                                ┌───────────────┐
                                │   Completed   │
                                │               │
                                │ - report ready│
                                │ - process dead│
                                └───────────────┘
```

### 3.2 State Invariants

**Uninitialized:**
- `weaver_manager.process` is `None`
- `otlp_config.endpoint` is `None`
- Cannot access coordination
- Cannot stop

**WeaverRunning:**
- `weaver_manager.process` is `Some(Child)`
- `otlp_config.endpoint` is `Some(String)`
- `coordination()` returns valid metadata
- Process is alive (can be verified)
- Can stop

**Completed:**
- `weaver_manager.process` is `None`
- `report_parser` has parsed report
- `report()` returns valid `ValidationReport`
- Cannot restart

**Enforcement:** Type system prevents invalid transitions at compile time.

```rust
pub async fn run_test(config_path: &Path) -> Result<()> {
    // 1. Parse TOML
    let config = TestConfig::load(config_path)?;

    // 2. Create orchestrator (if Weaver enabled)
    let orchestration = if let Some(weaver_config) = config.weaver {
        if weaver_config.enabled {
            let orchestrator = LiveCheckOrchestrator::from_toml_config(weaver_config)?;
            Some(orchestrator.start_with_fallback()?)
        } else {
            None
        }
    } else {
        None
    };

    // 3. Initialize OTEL with coordination
    let _guard = match &orchestration {
        Some(OrchestrationMode::LiveCheck(orch)) => {
            let mut otlp_config = OTLPExporterConfig::from_toml_config(config.otel.clone());
            otlp_config.configure_from_coordination(orch.coordination());

            let otel_config = otlp_config.to_otel_sdk_config()?;
            telemetry::init_otel(otel_config)?
        }
        _ => {
            // Fallback or disabled: use static config
            telemetry::init_otel(config.otel.unwrap_or_default())?
        }
    };

    // 4. Run test
    let env = CleanroomEnvironment::new().await?;
    let test_result = env.execute_test(&config).await;

    // 5. Stop orchestrator and validate
    let validation_result = match orchestration {
        Some(OrchestrationMode::LiveCheck(orch)) => {
            let completed = orch.stop_and_validate()?;
            let report = completed.report();

            println!("{}", ConformanceReportParser::generate_summary(report));

            if !completed.passed() {
                return Err(CleanroomError::validation_error(
                    format!("Weaver validation failed: {} violations", report.violations)
                ));
            }

            Ok(())
        }
        Some(OrchestrationMode::RegistryCheckOnly { registry_path, reason }) => {
            warn!("Weaver live-check unavailable: {}", reason);
            warn!("Running static registry check only");

            // Run static registry check
            run_registry_check(&registry_path)?;
            Ok(())
        }
        None => Ok(()), // Weaver disabled
    };

    // 6. Combine results
    test_result?;
    validation_result?;

    Ok(())
}

fn run_registry_check(registry_path: &Path) -> Result<()> {
    // Execute: weaver registry check -r <path>
    let output = Command::new("weaver")
        .args(["registry", "check", "-r", &registry_path.display().to_string()])
        .output()
        .map_err(|e| CleanroomError::internal_error(
            format!("Failed to run registry check: {}", e)
        ))?;

    if !output.status.success() {
        return Err(CleanroomError::validation_error(
            format!("Registry check failed:\n{}",
                String::from_utf8_lossy(&output.stderr))
        ));
    }

    Ok(())
}
```

## 5. Error Handling & Recovery

### 5.1 Error Taxonomy

**Startup Errors:**
1. **Weaver not installed** → Fallback to registry check
2. **Port conflict** → Retry with fallback ports
3. **Registry path invalid** → Fail fast with clear error
4. **Process spawn failure** → Fallback to registry check

**Runtime Errors:**
1. **Weaver crash** → Detect via monitor thread, fail test
2. **OTLP connectivity loss** → Continue test, warn about zero samples
3. **Violation detected (streaming)** → Log warning, continue test
4. **Inactivity timeout** → Force stop, generate partial report

**Shutdown Errors:**
1. **Graceful stop timeout** → Force kill, warn in report
2. **Report missing** → Return default report (failure status)
3. **Report parse error** → Log warning, return default report
4. **Zombie process** → Ensure cleanup in Drop

### 5.2 Fallback Strategy

```rust
pub enum OrchestrationMode {
    /// Full live validation
    LiveCheck(LiveCheckOrchestrator<WeaverRunning>),
    /// Fallback: static check only
    RegistryCheckOnly {
        registry_path: PathBuf,
        reason: String,
    },
}

impl LiveCheckOrchestrator<Uninitialized> {
    pub fn start_with_fallback(self) -> Result<OrchestrationMode> {
        match self.start_weaver() {
            Ok(running) => Ok(OrchestrationMode::LiveCheck(running)),
            Err(e) => {
                warn!("Live-check unavailable: {}", e);
                Ok(OrchestrationMode::RegistryCheckOnly {
                    registry_path: self.config.registry_path.clone(),
                    reason: format!("{}", e),
                })
            }
        }
    }
}
```

### 5.3 Resource Cleanup Guarantees

**Drop Implementation:**
```rust
impl<State> Drop for LiveCheckOrchestrator<State> {
    fn drop(&mut self) {
        // Always cleanup Weaver process
        self.weaver_manager.cleanup();

        // Warn if dropped in Running state (should call stop first)
        if TypeId::of::<State>() == TypeId::of::<WeaverRunning>() {
            warn!("LiveCheckOrchestrator dropped in Running state! Call stop_and_validate()");
        }
    }
}

impl Drop for WeaverProcessManager {
    fn drop(&mut self) {
        if let Some(mut process) = self.process.take() {
            debug!("Cleaning up Weaver process in Drop");
            let _ = process.kill();
            let _ = process.wait(); // Prevent zombie
        }

        if let Some(monitor) = self.monitor.take() {
            let _ = monitor.join();
        }
    }
}
```

## 8. Performance Considerations

### 8.1 Startup Overhead

**Weaver Startup:**
- Process spawn: ~200ms
- Port discovery: ~50ms (per range)
- Readiness wait: ~1000ms (fixed delay)
- **Total:** ~1.25 seconds

**Mitigation:**
- Parallel port discovery (check ranges concurrently)
- Smarter readiness detection (poll health endpoint instead of fixed delay)
- Process pooling (reuse Weaver across tests in watch mode)

### 8.2 Runtime Overhead

**OTLP Export:**
- gRPC overhead: ~1-5ms per batch
- Network I/O: localhost (minimal latency)
- Weaver validation: streaming (real-time, minimal buffering)

**Mitigation:**
- Use gRPC over HTTP (lower overhead)
- Batch telemetry exports
- Configure appropriate sample rates

### 8.3 Shutdown Overhead

**Graceful Stop:**
- SIGHUP send: ~1ms
- Process exit: ~500ms (report writing)
- Report parse: ~10ms (typical)
- **Total:** ~511ms

**Mitigation:**
- Use timeout for graceful stop (10s max, then force kill)
- Cache parsed reports to avoid re-parsing

### 8.4 Memory Footprint

**Weaver Process:**
- Base: ~50MB RSS
- Per-schema: ~5MB additional
- Peak: ~100MB for typical registry

**Monitoring Thread:**
- Stack size: ~2MB
- Buffered output: ~1MB

**Total Overhead:** ~103MB

## 10. Architecture Decision Records

### ADR-001: Type-Safe State Machines

**Context:** Need to prevent incorrect orchestrator usage (e.g., stopping before starting).

**Decision:** Use Rust's type system to encode state transitions at compile time.

**Alternatives:**
1. Runtime state enum with validation
2. Builder pattern with validation
3. Separate types for each state (CHOSEN)

**Rationale:**
- Compile-time guarantees eliminate runtime errors
- Self-documenting API (types show valid operations)
- Zero runtime overhead

**Consequences:**
- More complex type signatures
- Requires PhantomData and unsafe code for state transitions
- Better developer experience and safety

### ADR-002: Graceful Fallback to Registry Check

**Context:** Weaver might not be installed or might fail to start.

**Decision:** Automatically fallback to `weaver registry check` if live-check fails.

**Alternatives:**
1. Fail hard if Weaver unavailable
2. Skip validation entirely (REJECTED - defeats purpose)
3. Graceful fallback (CHOSEN)

**Rationale:**
- Maintains some validation (schema check) even when live-check unavailable
- Better user experience (tests don't fail due to missing Weaver)
- Still provides value (static schema validation)

**Consequences:**
- Users might not realize they're missing live validation
- Need clear warnings/logging about fallback mode

### ADR-003: Auto-Discovery of Ports

**Context:** Hard-coded ports cause conflicts in CI/CD and parallel testing.

**Decision:** Automatically discover available ports with fallback ranges.

**Alternatives:**
1. Hard-coded ports (4317, 8080)
2. User-specified ports in TOML
3. Auto-discovery with fallback (CHOSEN)

**Rationale:**
- Zero-configuration by default
- Supports parallel test execution
- Robust in CI/CD environments

**Consequences:**
- Requires port availability checking
- Potential race conditions (mitigated by binding check)

### ADR-004: Separate WeaverProcessManager

**Context:** Process management is complex and should be isolated.

**Decision:** Extract process lifecycle into dedicated `WeaverProcessManager`.

**Alternatives:**
1. Inline process management in orchestrator
2. Separate manager component (CHOSEN)
3. Use existing WeaverController directly

**Rationale:**
- Single Responsibility Principle
- Easier testing and mocking
- Reusable across different orchestration strategies

**Consequences:**
- Additional abstraction layer
- Clearer separation of concerns

### ADR-005: Zero Samples = Validation Failure

**Context:** Weaver might report success but receive zero telemetry samples.

**Decision:** Treat `sample_count == 0` as a validation failure, regardless of status.

**Alternatives:**
1. Trust Weaver's status field
2. Check sample_count > 0 (CHOSEN)
3. Make it configurable

**Rationale:**
- Zero samples means no validation occurred
- This is a critical failure mode to detect
- Prevents false positives

**Consequences:**
- Must ensure OTLP is properly configured
- May catch configuration issues early

## 13. Security Considerations

### 13.1 Port Binding

**Risk:** Binding to privileged ports (< 1024)

**Mitigation:**
- Validate port ranges in config
- Reject ports < 1024
- Use auto-discovery starting at 4317 (unprivileged)

### 13.2 Process Spawning

**Risk:** Command injection via registry path

**Mitigation:**
- Validate registry path in TOML parsing
- Use `Command::args()` (array form) not shell interpolation
- No user input in command construction

### 13.3 Report Parsing

**Risk:** JSON injection or malformed reports

**Mitigation:**
- Use serde for safe deserialization
- Validate all report fields
- Default to failure on parse errors

### 13.4 Zombie Processes

**Risk:** Orphaned Weaver processes consuming resources

**Mitigation:**
- Implement Drop for cleanup
- Use SIGHUP for graceful shutdown
- Cleanup orphans at startup
- Always wait() on child processes

## Appendix B: Glossary

- **Live-Check:** Real-time telemetry validation using Weaver
- **Registry Check:** Static schema validation without runtime telemetry
- **Coordination:** Process of synchronizing OTLP endpoint with Weaver
- **Conformance Report:** Weaver's JSON output describing validation results
- **Orchestration:** End-to-end lifecycle management of Weaver validation
- **Type-Safe State Machine:** Compile-time enforced state transitions
- **Graceful Degradation:** Fallback to reduced functionality on errors
