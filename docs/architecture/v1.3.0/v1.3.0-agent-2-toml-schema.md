# clnrm v1.3.0 TOML Configuration Schema: Weaver Live-Check Support

## Architecture Decision Record

**Status**: Proposed
**Date**: 2025-10-31
**Context**: clnrm v1.3.0 requires comprehensive TOML configuration for Weaver live-check validation
**Decision**: Extend existing TOML schema with backward-compatible `[weaver]` and `[test.live_check]` sections

---

## 1. Complete TOML Schema Definition

### 1.1 Core Weaver Configuration

```toml
# ============================================================================
# WEAVER LIVE-CHECK CONFIGURATION (v1.3.0+)
# ============================================================================

[weaver]
# Enable Weaver live-check validation
# Default: true (if [weaver] section present)
# Type: boolean
enabled = true

# Registry path for Weaver schema definitions
# Default: "registry" (relative to installation directory)
# Type: string (path)
# Accepts: Absolute paths (/path/to/registry), relative paths (./registry), home paths (~/registry)
registry_path = "registry/"

# OTLP gRPC port for telemetry ingestion
# Default: 0 (auto-discover free port)
# Type: u16 (1024-65535, or 0 for auto)
# Note: Ports < 1024 require root privileges and are rejected
otlp_port = 0

# Admin port for Weaver control interface
# Default: 0 (auto-discover free port)
# Type: u16 (1024-65535, or 0 for auto)
# Note: Must differ from otlp_port
admin_port = 0

# Output directory for validation reports
# Default: "./validation_output"
# Type: string (path)
output_dir = "./validation_output"

# Enable real-time streaming validation output
# Default: false
# Type: boolean
# Effect: Shows violations as they occur, not just at end
stream = false

# Fail fast on first violation
# Default: false
# Type: boolean
# Effect: Stop test execution immediately on first schema violation
fail_fast = false
```

### 1.2 Advanced Validation Configuration

```toml
[weaver.validation]
# Validation strictness mode
# Default: "strict"
# Type: enum["strict", "lenient", "80_20"]
# - strict: All schema violations fail the test
# - lenient: Only critical violations fail (missing required attributes)
# - 80_20: Focus on critical 20% of telemetry (see [weaver.80_20])
mode = "strict"

# Fail test execution on schema violations
# Default: true
# Type: boolean
# Effect: Test exits non-zero if Weaver detects violations
fail_on_violation = true

# Coverage threshold (percentage of expected telemetry observed)
# Default: 80.0
# Type: f64 (0.0-100.0)
# Effect: Fail if less than N% of expected spans/metrics emitted
coverage_threshold = 80.0

# Timeout for waiting for telemetry after test completes
# Default: 5 (seconds)
# Type: u64
# Effect: How long to wait for final telemetry flush
inactivity_timeout = 5

# Diagnostic output format
# Default: "ansi"
# Type: enum["ansi", "json", "gh_workflow_command"]
# - ansi: Colored terminal output
# - json: Machine-readable JSON
# - gh_workflow_command: GitHub Actions annotations
diagnostic_format = "ansi"
```

### 1.3 80/20 Validation Mode

[weaver.80_20]

## 2. Backward Compatibility

### 2.1 Migration Strategy: v1.2.1 → v1.3.0

**Principle**: All v1.2.1 TOML files MUST work in v1.3.0 without changes.

#### Compatibility Rules

1. **No Breaking Changes**
   - All existing sections remain valid
   - All existing fields retain same semantics
   - Default behavior unchanged unless `[weaver]` section added

2. **Opt-In Design**
   - Weaver validation is DISABLED by default
   - Only enabled when `[weaver]` section present OR `--validate` CLI flag used
   - Existing tests run exactly as before

3. **Graceful Degradation**
   - If Weaver not installed: Warning logged, validation skipped
   - If registry not found: Clear error with path to fix
   - If validation fails: Test fails with actionable error message

#### Migration Examples

**v1.2.1 TOML (No Changes Required)**
```toml
[test.metadata]
name = "basic_test"
description = "Simple test"

[services.alpine]
type = "generic_container"
image = "alpine:latest"

[[steps]]
name = "hello"
command = ["echo", "hello"]
expected_output_regex = "hello"
```

**v1.3.0 TOML (Opt-In Validation)**
```toml
[test.metadata]
name = "basic_test"
description = "Simple test"

# NEW: Enable Weaver validation
[weaver]
enabled = true
registry_path = "registry/"

[services.alpine]
type = "generic_container"
image = "alpine:latest"

[[steps]]
name = "hello"
command = ["echo", "hello"]
expected_output_regex = "hello"
```

**v1.3.0 TOML (Advanced Validation)**
```toml
[test.metadata]
name = "production_test"
description = "Production-ready test with strict validation"

# Comprehensive Weaver configuration
[weaver]
enabled = true
registry_path = "registry/"
fail_fast = true
stream = true

[weaver.validation]
mode = "strict"
fail_on_violation = true
coverage_threshold = 95.0

[weaver.reports]
json_report = true
html_report = true
junit_report = true

[services.app]
type = "generic_container"
image = "myapp:latest"

[[steps]]
name = "integration_test"
command = ["./run_tests.sh"]
expected_exit_code = 0
```

### 2.2 Deprecation Policy

**NO deprecations in v1.3.0**. All existing features remain fully supported.

**Future consideration (v2.0.0)**:
- May deprecate manual OTEL configuration in favor of Weaver-driven config
- Will provide migration tools and 6-month deprecation notice

## 3. Validation Rules & Type Constraints

### 3.1 Type Definitions

```rust
pub struct WeaverConfig {
    enabled: bool,                    // Required, default: true
    registry_path: String,            // Required, default: "registry"
    otlp_port: u16,                   // Range: 0 or 1024-65535
    admin_port: u16,                  // Range: 0 or 1024-65535, != otlp_port
    output_dir: String,               // Valid path string
    stream: bool,                     // Required, default: false
    fail_fast: bool,                  // Required, default: false
}

pub struct ValidationConfig {
    mode: ValidationMode,             // Enum: strict | lenient | 80_20
    fail_on_violation: bool,          // Required, default: true
    coverage_threshold: f64,          // Range: 0.0-100.0
    inactivity_timeout: u64,          // Seconds, > 0
    diagnostic_format: DiagnosticFormat, // Enum: ansi | json | gh_workflow_command

pub struct EightyTwentyConfig {
    enabled: bool,                    // Required, default: false
    critical_spans: Vec<String>,      // Non-empty if enabled
    required_attributes: Vec<String>, // Non-empty if enabled
    optional_attributes: Vec<String>, // Can be empty
    critical_span_coverage: f64,      // Range: 0.0-100.0
    required_attribute_coverage: f64, // Range: 0.0-100.0
    optional_attribute_coverage: f64, // Range: 0.0-100.0
}
```

### 3.2 Validation Constraints

| Field | Constraint | Error Message |
|-------|-----------|---------------|
| `weaver.otlp_port` | 0 or >= 1024 | "OTLP port must be >= 1024 or 0 for auto-discovery" |
| `weaver.admin_port` | 0 or >= 1024 | "Admin port must be >= 1024 or 0 for auto-discovery" |
| `weaver.otlp_port` vs `weaver.admin_port` | Must differ if both > 0 | "OTLP port and admin port must be different" |
| `weaver.validation.coverage_threshold` | 0.0-100.0 | "Coverage threshold must be between 0.0 and 100.0" |
| `weaver.validation.mode` | One of: strict, lenient, 80_20 | "Invalid validation mode: {mode}" |
| `weaver.80_20.critical_spans` | Non-empty if 80_20 enabled | "80/20 mode requires at least one critical span" |
| `weaver.registry_path` | Must exist or be creatable | "Registry path not found: {path}" |

## 4. Configuration Inheritance & Composition

### 4.1 Global vs Test-Specific Configuration

**Hierarchy** (highest to lowest precedence):
1. CLI flags (`--validate`, `--weaver-registry`, etc.)
2. Test TOML `[weaver]` section
3. Global config file `~/.clnrm/config.toml`
4. Environment variables (`CLNRM_WEAVER_*`)
5. Built-in defaults

### 4.2 Global Configuration File

**Location**: `~/.clnrm/config.toml`

```toml
# Global Weaver defaults for all tests
[weaver]
registry_path = "/usr/local/share/clnrm/registry"
output_dir = "~/clnrm-validation"

[weaver.validation]
mode = "strict"
diagnostic_format = "ansi"

[weaver.collector]
use_existing = true
endpoint = "http://localhost:4317"
```

### 4.3 Environment Variable Overrides

```bash
# Override registry path
export CLNRM_WEAVER_REGISTRY_PATH=/custom/registry

# Override validation mode
export CLNRM_WEAVER_VALIDATION_MODE=80_20

# Override output directory
export CLNRM_WEAVER_OUTPUT_DIR=/tmp/validation

# Disable Weaver entirely
export CLNRM_WEAVER_ENABLED=false
```

### 4.4 CLI Flag Overrides

```bash
# Enable validation (highest precedence)
clnrm run tests/ --validate

# Custom registry path
clnrm run tests/ --weaver-registry=/custom/registry

# Custom output directory
clnrm run tests/ --weaver-output=/tmp/validation

# Strict mode
clnrm run tests/ --weaver-mode=strict

# Fail fast
clnrm run tests/ --weaver-fail-fast
```

## 6. Implementation Architecture

### 6.1 Configuration Loading Flow

```
1. Load TOML file
   ├─> Parse with serde
   └─> Validate schema

2. Merge configurations
   ├─> Built-in defaults
   ├─> Environment variables
   ├─> Global config file
   ├─> Test TOML
   └─> CLI flags (highest precedence)

3. Validate merged config
   ├─> Type constraints
   ├─> Value ranges
   ├─> Logical consistency
   └─> Path existence

4. Convert to runtime config
   ├─> Resolve paths (relative → absolute)
   ├─> Discover ports (0 → actual port)
   └─> Initialize telemetry
```

### 6.2 Runtime Configuration Structure

```rust
// Config as parsed from TOML
pub struct WeaverConfig { /* serde::Deserialize */ }

// Config after resolution and validation
pub struct WeaverRuntimeConfig {
    registry_path: PathBuf,           // Absolute path
    otlp_port: u16,                   // Actual port (not 0)
    admin_port: u16,                  // Actual port (not 0)
    output_dir: PathBuf,              // Absolute path
    validation: ValidationRuntimeConfig,
    collector: CollectorRuntimeConfig,
    // ...
}

impl WeaverConfig {
    pub fn to_runtime(&self) -> Result<WeaverRuntimeConfig> {
        // Port discovery
        let otlp_port = if self.otlp_port == 0 {
            discover_free_port()?
        } else {
            self.otlp_port
        };

        // Path resolution
        let registry_path = resolve_registry_path(&self.registry_path)?;

        // Validation
        self.validate()?;

        Ok(WeaverRuntimeConfig { /* ... */ })
    }
}
```

### 6.3 Error Handling

```rust
pub enum WeaverConfigError {
    InvalidPort { port: u16, field: String },
    PortConflict { otlp: u16, admin: u16 },
    InvalidRange { value: f64, field: String, min: f64, max: f64 },
    InvalidMode { mode: String, valid: Vec<String> },
    RegistryNotFound { path: PathBuf },
    ValidationFailed { errors: Vec<String> },
}

impl Display for WeaverConfigError {
    fn fmt(&self, f: &mut Formatter) -> fmt::Result {
        match self {
            Self::InvalidPort { port, field } => {
                write!(f, "{} port {} is invalid (must be >= 1024 or 0 for auto-discovery)", field, port)
            }
            Self::PortConflict { otlp, admin } => {
                write!(f, "OTLP port {} and admin port {} must be different", otlp, admin)
            }
            Self::InvalidRange { value, field, min, max } => {
                write!(f, "{} value {} is out of range [{}, {}]", field, value, min, max)
            }
            Self::RegistryNotFound { path } => {
                write!(f, "Weaver registry not found at {:?}. Run: mkdir -p {:?}", path, path)
            }
            // ...
        }
    }
}
```

## 7. Testing Strategy

### 7.1 Configuration Validation Tests

```rust
#[test]
fn test_weaver_config_defaults() {
    let config = WeaverConfig::default();
    assert_eq!(config.enabled, true);
    assert_eq!(config.registry_path, "registry");
    assert_eq!(config.otlp_port, 0);
}

#[test]
fn test_weaver_config_port_validation() {
    let mut config = WeaverConfig::default();
    config.otlp_port = 80; // Invalid (< 1024)

    let result = config.validate();
    assert!(result.is_err());
    assert_eq!(
        result.unwrap_err().to_string(),
        "OTLP port must be >= 1024 or 0 for auto-discovery"
    );
}

#[test]
fn test_weaver_config_port_conflict() {
    let mut config = WeaverConfig::default();
    config.otlp_port = 5000;
    config.admin_port = 5000; // Conflict

    let result = config.validate();
    assert!(result.is_err());
    assert!(result.unwrap_err().to_string().contains("must be different"));
}
```
