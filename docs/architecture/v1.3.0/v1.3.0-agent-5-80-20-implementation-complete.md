### 2. Coverage Calculation

**Overall Coverage**:
```rust
fn calculate_coverage(&self, report: &ConformanceReport) -> f64 {
    let total = report.required_spans.len() + report.required_attributes.len();
    let present = present_spans + present_attrs;
    (present as f64 / total as f64) * 100.0
}
```

**Critical Coverage (80/20 mode)**:
```rust
fn calculate_critical_coverage(
    &self,
    report: &ConformanceReport,
    eighty_twenty: &EightyTwentyConfig,
) -> f64 {
    let total = eighty_twenty.critical_spans.len()
              + eighty_twenty.required_attributes.len();
    let present = present_critical_spans + present_critical_attrs;
    (present as f64 / total as f64) * 100.0
}
```
