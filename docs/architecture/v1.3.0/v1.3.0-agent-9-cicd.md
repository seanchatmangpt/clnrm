## Architecture Overview

### The Weaver Validation Pipeline

```
┌──────────────────────────────────────────────────────────────────────┐
│                      CI/CD Pipeline Flow                              │
└──────────────────────────────────────────────────────────────────────┘

    Developer           GitHub Actions         Weaver              Gate
        │                     │                  │                  │
        │  git push           │                  │                  │
        ├────────────────────>│                  │                  │
        │                     │                  │                  │
        │                     │ Build + Compile  │                  │
        │                     ├─────────────────>│                  │
        │                     │                  │                  │
        │                     │ Run Tests (OTLP) │                  │
        │                     ├─────────────────>│                  │
        │                     │                  │ Validate         │
        │                     │                  ├─────────────────>│
        │                     │                  │ Check Conformance│
        │                     │                  │                  │
        │                     │                  │<─────────────────┤
        │                     │<─────────────────┤ Pass/Fail        │
        │                     │                  │                  │
        │<────────────────────┤                  │                  │
        │  Result             │                  │                  │
```

### Key Principles

1. **Weaver as Single Source of Truth**: Schema validation is the ONLY proof of correctness
2. **Fail Fast**: Block merge immediately on violations
3. **Zero False Positives**: Traditional tests can lie, schemas don't
4. **Production Parity**: CI environment mirrors production telemetry setup
5. **Developer Feedback**: Clear, actionable error messages

### Integration Points

- **PR Validation**: Every PR must pass Weaver validation
- **Main Branch Protection**: Strict mode on main/master
- **Release Gates**: 100% conformance required for tags
- **Pre-Commit Hooks**: Local validation before push
- **Performance Benchmarking**: Track validation overhead

## GitHub Actions Workflows

### 1. Pull Request Validation (Complete Workflow)

**File:** `.github/workflows/weaver-pr-validation.yml`

```yaml
name: Weaver PR Validation

on:
  pull_request:
    branches: [main, master, develop]
    paths:
      - 'src/**'
      - 'crates/**'
      - 'registry/**'
      - 'tests/**'
      - '.github/workflows/weaver-pr-validation.yml'

env:
  RUST_BACKTRACE: 1
  CARGO_TERM_COLOR: always
  WEAVER_VERSION: "0.16.1"

jobs:
  # Gate 1: Schema Validation
  schema-check:
    name: "Gate 1: Schema Validation"
    runs-on: ubuntu-latest
    timeout-minutes: 5

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Cache Weaver binary
        id: cache-weaver
        uses: actions/cache@v4
        with:
          path: ~/.cargo/bin/weaver
          key: weaver-${{ env.WEAVER_VERSION }}-${{ runner.os }}

      - name: Install Weaver
        if: steps.cache-weaver.outputs.cache-hit != 'true'
        run: |
          cargo install weaver-forge --version ${{ env.WEAVER_VERSION }}
          weaver --version

      - name: Validate registry schemas
        id: schema_check
        run: |
          echo "::group::Schema Validation"
          weaver registry check --registry registry/ --future
          EXIT_CODE=$?
          echo "::endgroup::"

          if [ $EXIT_CODE -eq 0 ]; then
            echo "✅ Schema validation PASSED"
            echo "status=passed" >> $GITHUB_OUTPUT
          else
            echo "❌ Schema validation FAILED"
            echo "status=failed" >> $GITHUB_OUTPUT
            exit 1
          fi

      - name: Generate schema report
        if: always()
        run: |
          echo "## 📋 Schema Validation Report" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY
          echo "**Status:** ${{ steps.schema_check.outputs.status }}" >> $GITHUB_STEP_SUMMARY
          echo "**Registry Path:** \`registry/\`" >> $GITHUB_STEP_SUMMARY

  # Gate 2: Build & Test
  build-and-test:
    name: "Gate 2: Build & Test"
    runs-on: ubuntu-latest
    needs: schema-check
    timeout-minutes: 15

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Install Rust toolchain
        uses: actions-rust-lang/setup-rust-toolchain@v1
        with:
          toolchain: stable
          components: clippy

      - name: Cache cargo dependencies
        uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/registry
            ~/.cargo/git
            target/
          key: ${{ runner.os }}-cargo-${{ hashFiles('**/Cargo.lock') }}
          restore-keys: |
            ${{ runner.os }}-cargo-

      - name: Run clippy
        run: |
          cargo clippy --all-targets --features otel -- -D warnings

      - name: Build with OTEL features
        run: |
          cargo build --release --features otel

      - name: Run unit tests
        run: |
          cargo test --lib --features otel

      - name: Upload build artifacts
        uses: actions/upload-artifact@v4
        with:
          name: clnrm-binary
          path: target/release/clnrm
          retention-days: 1

  # Gate 3: Weaver Live Validation
  weaver-live-check:
    name: "Gate 3: Weaver Live Validation"
    runs-on: ubuntu-latest
    needs: build-and-test
    timeout-minutes: 10

    services:
      otel-collector:
        image: otel/opentelemetry-collector-contrib:latest
        ports:
          - 4317:4317
          - 4318:4318
        options: >-
          --health-cmd="curl -f http://localhost:13133/health"
          --health-interval=10s
          --health-timeout=5s
          --health-retries=3

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Install Rust toolchain
        uses: actions-rust-lang/setup-rust-toolchain@v1
        with:
          toolchain: stable

      - name: Cache Weaver binary
        id: cache-weaver
        uses: actions/cache@v4
        with:
          path: ~/.cargo/bin/weaver
          key: weaver-${{ env.WEAVER_VERSION }}-${{ runner.os }}

      - name: Install Weaver
        if: steps.cache-weaver.outputs.cache-hit != 'true'
        run: |
          cargo install weaver-forge --version ${{ env.WEAVER_VERSION }}

      - name: Start Weaver live-check
        id: weaver
        run: |
          mkdir -p validation_output
          echo "🔍 Starting Weaver live-check"

          weaver registry live-check \
            --registry registry/ \
            --otlp-grpc-port 4317 \
            --admin-port 8080 \
            --output validation_output/ \
            --format json \
            --inactivity-timeout 30 \
            --no-stream &

          WEAVER_PID=$!
          echo "pid=${WEAVER_PID}" >> $GITHUB_OUTPUT
          echo "✅ Weaver started (PID: ${WEAVER_PID})"

          # Wait for Weaver to be ready
          max_wait=30
          elapsed=0
          while [ $elapsed -lt $max_wait ]; do
            if curl -sf http://localhost:8080/health >/dev/null 2>&1; then
              echo "✅ Weaver is healthy"
              break
            fi
            sleep 1
            elapsed=$((elapsed + 1))
          done

          if [ $elapsed -ge $max_wait ]; then
            echo "❌ Weaver health check timeout"
            exit 1
          fi

      - name: Run integration tests with OTLP
        env:
          OTEL_EXPORTER_OTLP_ENDPOINT: http://localhost:4317
          OTEL_SERVICE_NAME: clnrm-ci-pr-${{ github.event.pull_request.number }}
          RUST_LOG: info
        run: |
          echo "🧪 Running tests with OTLP export"
          cargo test --features otel --workspace -- --test-threads=1 --nocapture

          # Give time for final telemetry flush
          sleep 3

      - name: Stop Weaver and generate report
        if: always()
        run: |
          WEAVER_PID="${{ steps.weaver.outputs.pid }}"

          if [ ! -z "$WEAVER_PID" ]; then
            echo "🛑 Stopping Weaver (PID: ${WEAVER_PID})"

            # Graceful shutdown with SIGHUP
            kill -HUP $WEAVER_PID || true
            sleep 3

            # Force kill if still running
            kill -9 $WEAVER_PID 2>/dev/null || true
          fi

      - name: Parse validation report
        id: validation
        if: always()
        run: |
          if [ -f validation_output/live_check.json ]; then
            echo "::group::Validation Report"
            cat validation_output/live_check.json | jq .
            echo "::endgroup::"

            # Extract metrics
            VIOLATIONS=$(jq -r '.statistics.advice_level_counts.violation // 0' \
                         validation_output/live_check.json)
            WARNINGS=$(jq -r '.statistics.advice_level_counts.warning // 0' \
                       validation_output/live_check.json)
            COVERAGE=$(jq -r '.statistics.registry_coverage // 0' \
                       validation_output/live_check.json)
            SAMPLE_COUNT=$(jq -r '.sample_count // 0' \
                           validation_output/live_check.json)

            echo "violations=${VIOLATIONS}" >> $GITHUB_OUTPUT
            echo "warnings=${WARNINGS}" >> $GITHUB_OUTPUT
            echo "coverage=${COVERAGE}" >> $GITHUB_OUTPUT
            echo "sample_count=${SAMPLE_COUNT}" >> $GITHUB_OUTPUT

            # CRITICAL: Check for zero telemetry (false positive)
            if [ "$SAMPLE_COUNT" -eq 0 ]; then
              echo "::error::CRITICAL: Zero telemetry samples received"
              echo "::error::This indicates telemetry is NOT working"
              echo "status=no_telemetry" >> $GITHUB_OUTPUT
              exit 1
            fi

            # Check for violations
            if [ "$VIOLATIONS" -gt 0 ]; then
              echo "::error::Weaver detected ${VIOLATIONS} violations"
              echo "::group::Violation Details"
              jq -r '.advices[]? | select(.advice_level == "violation") |
                     "- \(.signal_type): \(.message)"' \
                validation_output/live_check.json
              echo "::endgroup::"
              echo "status=failed" >> $GITHUB_OUTPUT
              exit 1
            fi

            # Check coverage threshold (80%)
            COVERAGE_PCT=$(echo "$COVERAGE * 100" | bc -l | cut -d. -f1)
            if [ "$COVERAGE_PCT" -lt 80 ]; then
              echo "::warning::Coverage ${COVERAGE_PCT}% below 80% threshold"
              echo "status=low_coverage" >> $GITHUB_OUTPUT
              exit 1
            fi

            echo "✅ Validation PASSED"
            echo "status=passed" >> $GITHUB_OUTPUT
          else
            echo "::error::Validation report not found"
            echo "status=no_report" >> $GITHUB_OUTPUT
            exit 1
          fi

      - name: Generate validation summary
        if: always()
        run: |
          echo "## 🎯 Weaver Live-Check Results" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY

          STATUS="${{ steps.validation.outputs.status }}"
          VIOLATIONS="${{ steps.validation.outputs.violations }}"
          WARNINGS="${{ steps.validation.outputs.warnings }}"
          COVERAGE="${{ steps.validation.outputs.coverage }}"
          SAMPLES="${{ steps.validation.outputs.sample_count }}"

          if [ "$STATUS" = "passed" ]; then
            echo "### ✅ PASSED" >> $GITHUB_STEP_SUMMARY
          else
            echo "### ❌ FAILED" >> $GITHUB_STEP_SUMMARY
          fi

          echo "" >> $GITHUB_STEP_SUMMARY
          echo "| Metric | Value |" >> $GITHUB_STEP_SUMMARY
          echo "|--------|-------|" >> $GITHUB_STEP_SUMMARY
          echo "| Violations | ${VIOLATIONS} |" >> $GITHUB_STEP_SUMMARY
          echo "| Warnings | ${WARNINGS} |" >> $GITHUB_STEP_SUMMARY
          echo "| Coverage | $(echo "$COVERAGE * 100" | bc -l | cut -d. -f1)% |" >> $GITHUB_STEP_SUMMARY
          echo "| Samples | ${SAMPLES} |" >> $GITHUB_STEP_SUMMARY
          echo "| Status | ${STATUS} |" >> $GITHUB_STEP_SUMMARY

      - name: Upload validation artifacts
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: weaver-validation-report
          path: validation_output/
          retention-days: 30

      - name: Comment on PR
        if: always() && github.event_name == 'pull_request'
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');

            let reportPath = 'validation_output/live_check.json';
            if (!fs.existsSync(reportPath)) {
              await github.rest.issues.createComment({
                issue_number: context.issue.number,
                owner: context.repo.owner,
                repo: context.repo.repo,
                body: '## ⚠️ Weaver Validation Report Missing\n\nNo validation report was generated. Check workflow logs.'
              });
              return;
            }

            const report = JSON.parse(fs.readFileSync(reportPath, 'utf8'));
            const stats = report.statistics || {};
            const violations = stats.advice_level_counts?.violation || 0;
            const warnings = stats.advice_level_counts?.warning || 0;
            const coverage = ((stats.registry_coverage || 0) * 100).toFixed(1);
            const samples = report.sample_count || 0;

            let body = '## 🔍 Weaver Live-Check Results\n\n';

            if (violations === 0 && samples > 0 && coverage >= 80) {
              body += '### ✅ PASSED\n\n';
              body += 'All telemetry conforms to schema!\n\n';
            } else {
              body += '### ❌ FAILED\n\n';
            }

            body += '| Metric | Value |\n';
            body += '|--------|-------|\n';
            body += `| Violations | ${violations} |\n`;
            body += `| Warnings | ${warnings} |\n`;
            body += `| Coverage | ${coverage}% |\n`;
            body += `| Samples Received | ${samples} |\n\n`;

            if (samples === 0) {
              body += '🚨 **CRITICAL:** Zero telemetry samples received!\n\n';
              body += 'This indicates OTLP export is not working. Check:\n';
              body += '- `OTEL_EXPORTER_OTLP_ENDPOINT` environment variable\n';
              body += '- Telemetry initialization in tests\n';
              body += '- Network connectivity to collector\n\n';
            }

            if (violations > 0) {
              body += '### Violations:\n\n';
              const violationAdvices = report.advices?.filter(a => a.advice_level === 'violation') || [];
              violationAdvices.slice(0, 5).forEach(adv => {
                body += `- **${adv.signal_type}:** ${adv.message}\n`;
              });
              if (violationAdvices.length > 5) {
                body += `\n_...and ${violationAdvices.length - 5} more violations_\n`;
              }
              body += '\n';
            }

            body += '\n📊 [View full report in workflow artifacts](';
            body += `${context.payload.repository.html_url}/actions/runs/${context.runId})`;

            await github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: body
            });

  # Final gate: Quality score
  quality-gate:
    name: "Gate 4: Quality Score"
    runs-on: ubuntu-latest
    needs: [schema-check, build-and-test, weaver-live-check]
    if: always()

    steps:
      - name: Download validation report
        uses: actions/download-artifact@v4
        with:
          name: weaver-validation-report
          path: validation_output/

      - name: Calculate quality score
        id: quality
        run: |
          # Quality scoring (out of 100):
          # - Schema valid: 20 points
          # - Build success: 20 points
          # - Zero violations: 40 points
          # - Coverage >= 80%: 20 points

          SCORE=0

          # Schema check (20 points)
          SCORE=$((SCORE + 20))

          # Build check (20 points)
          SCORE=$((SCORE + 20))

          # Violations check (40 points if zero)
          if [ -f validation_output/live_check.json ]; then
            VIOLATIONS=$(jq -r '.statistics.advice_level_counts.violation // 1' \
                         validation_output/live_check.json)
            if [ "$VIOLATIONS" -eq 0 ]; then
              SCORE=$((SCORE + 40))
            fi

            # Coverage check (20 points if >= 80%)
            COVERAGE=$(jq -r '.statistics.registry_coverage // 0' \
                       validation_output/live_check.json)
            COVERAGE_PCT=$(echo "$COVERAGE * 100" | bc -l | cut -d. -f1)
            if [ "$COVERAGE_PCT" -ge 80 ]; then
              SCORE=$((SCORE + 20))
            fi
          fi

          echo "score=${SCORE}" >> $GITHUB_OUTPUT
          echo "🏆 Quality Score: ${SCORE}/100"

          # Gate threshold: 75/100
          if [ "$SCORE" -ge 75 ]; then
            echo "✅ Quality gate PASSED (${SCORE} >= 75)"
            echo "status=passed" >> $GITHUB_OUTPUT
            exit 0
          else
            echo "❌ Quality gate FAILED (${SCORE} < 75)"
            echo "status=failed" >> $GITHUB_OUTPUT
            exit 1
          fi

      - name: Post quality score
        run: |
          echo "## 🏆 Quality Score: ${{ steps.quality.outputs.score }}/100" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY
          echo "**Status:** ${{ steps.quality.outputs.status }}" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY

          if [ "${{ steps.quality.outputs.status }}" = "passed" ]; then
            echo "✅ All gates passed - PR ready to merge!" >> $GITHUB_STEP_SUMMARY
          else
            echo "❌ Quality gate failed - address issues before merge" >> $GITHUB_STEP_SUMMARY
          fi
```

```yaml
name: Main Branch Protection

on:
  push:
    branches: [main, master]

env:
  RUST_BACKTRACE: 1
  CARGO_TERM_COLOR: always
  WEAVER_VERSION: "0.16.1"

jobs:
  strict-validation:
    name: Strict Weaver Validation (Main Branch)
    runs-on: ubuntu-latest
    timeout-minutes: 20

    services:
      otel-collector:
        image: otel/opentelemetry-collector-contrib:latest
        ports:
          - 4317:4317

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Install Rust toolchain
        uses: actions-rust-lang/setup-rust-toolchain@v1
        with:
          toolchain: stable

      - name: Install Weaver
        run: |
          cargo install weaver-forge --version ${{ env.WEAVER_VERSION }}

      - name: Build with all features
        run: |
          cargo build --release --all-features

      - name: Start Weaver (strict mode)
        run: |
          weaver registry live-check \
            --registry registry/ \
            --otlp-grpc-port 4317 \
            --format json \
            --output validation_output/ \
            --inactivity-timeout 60 \
            --no-stream &
          echo $! > weaver.pid
          sleep 5

      - name: Run comprehensive test suite
        env:
          OTEL_EXPORTER_OTLP_ENDPOINT: http://localhost:4317
          OTEL_SERVICE_NAME: clnrm-main-branch
        run: |
          # Run ALL tests
          cargo test --all-features --workspace -- --test-threads=1

          # Run integration tests
          cargo test --test '*' --features otel

          # Run property tests
          cargo test --features proptest

          sleep 5

      - name: Stop Weaver
        if: always()
        run: |
          kill -HUP $(cat weaver.pid) || true
          wait $(cat weaver.pid) || true

      - name: Enforce strict requirements
        run: |
          VIOLATIONS=$(jq -r '.statistics.advice_level_counts.violation // 0' \
                       validation_output/live_check.json)
          WARNINGS=$(jq -r '.statistics.advice_level_counts.warning // 0' \
                     validation_output/live_check.json)
          COVERAGE=$(jq -r '.statistics.registry_coverage // 0' \
                     validation_output/live_check.json)
          COVERAGE_PCT=$(echo "$COVERAGE * 100" | bc -l | cut -d. -f1)

          FAILED=0

          # STRICT: Zero violations
          if [ "$VIOLATIONS" -gt 0 ]; then
            echo "::error::Violations not allowed on main branch: ${VIOLATIONS}"
            FAILED=1
          fi

          # STRICT: Zero warnings
          if [ "$WARNINGS" -gt 0 ]; then
            echo "::error::Warnings not allowed on main branch: ${WARNINGS}"
            FAILED=1
          fi

          # STRICT: 90% coverage (higher than PR requirement)
          if [ "$COVERAGE_PCT" -lt 90 ]; then
            echo "::error::Coverage too low for main: ${COVERAGE_PCT}% < 90%"
            FAILED=1
          fi

          if [ "$FAILED" -eq 1 ]; then
            echo "❌ STRICT VALIDATION FAILED"
            exit 1
          fi

          echo "✅ Strict validation PASSED"

      - name: Upload validation report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: main-branch-validation
          path: validation_output/
          retention-days: 90

      - name: Notify on failure
        if: failure()
        run: |
          echo "::error::Main branch validation FAILED - reverting may be necessary"
```

### 3. Parallel Test Matrix

**File:** `.github/workflows/weaver-matrix-tests.yml`

```yaml
name: Parallel Test Matrix

on:
  pull_request:
    branches: [main]
  workflow_dispatch:

jobs:
  matrix-tests:
    name: Test Suite (${{ matrix.suite }})
    runs-on: ubuntu-latest
    timeout-minutes: 15

    strategy:
      fail-fast: false
      matrix:
        suite:
          - unit
          - integration
          - docker
          - performance

    services:
      otel-collector:
        image: otel/opentelemetry-collector-contrib:latest
        ports:
          # Dynamic port allocation per job
          - ${{ 4317 + matrix.port_offset }}:4317

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Calculate port offset
        id: ports
        run: |
          case "${{ matrix.suite }}" in
            unit) echo "offset=0" >> $GITHUB_OUTPUT ;;
            integration) echo "offset=10" >> $GITHUB_OUTPUT ;;
            docker) echo "offset=20" >> $GITHUB_OUTPUT ;;
            performance) echo "offset=30" >> $GITHUB_OUTPUT ;;
          esac

      - name: Install Weaver
        run: |
          cargo install weaver-forge --version 0.16.1

      - name: Start Weaver (suite-specific port)
        run: |
          OTLP_PORT=$((4317 + ${{ steps.ports.outputs.offset }}))
          ADMIN_PORT=$((8080 + ${{ steps.ports.outputs.offset }}))

          weaver registry live-check \
            --registry registry/ \
            --otlp-grpc-port $OTLP_PORT \
            --admin-port $ADMIN_PORT \
            --output validation_output_${{ matrix.suite }}/ \
            --format json &
          echo $! > weaver.pid
          sleep 3

      - name: Run ${{ matrix.suite }} tests
        env:
          OTEL_EXPORTER_OTLP_ENDPOINT: http://localhost:$((4317 + steps.ports.outputs.offset))
          OTEL_SERVICE_NAME: clnrm-${{ matrix.suite }}
        run: |
          case "${{ matrix.suite }}" in
            unit)
              cargo test --lib --features otel
              ;;
            integration)
              cargo test --test integration_* --features otel
              ;;
            docker)
              cargo test --test docker_* --features otel
              ;;
            performance)
              cargo test --test performance_* --features otel
              ;;
          esac

      - name: Stop Weaver
        if: always()
        run: |
          kill -HUP $(cat weaver.pid) || true

      - name: Upload suite results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: validation-${{ matrix.suite }}
          path: validation_output_${{ matrix.suite }}/
          retention-days: 7

  aggregate-results:
    name: Aggregate Matrix Results
    runs-on: ubuntu-latest
    needs: matrix-tests
    if: always()

    steps:
      - name: Download all suite results
        uses: actions/download-artifact@v4
        with:
          path: all_validations/

      - name: Aggregate violations
        run: |
          TOTAL_VIOLATIONS=0
          TOTAL_WARNINGS=0
          TOTAL_SAMPLES=0

          for dir in all_validations/validation-*/; do
            if [ -f "$dir/live_check.json" ]; then
              V=$(jq -r '.statistics.advice_level_counts.violation // 0' "$dir/live_check.json")
              W=$(jq -r '.statistics.advice_level_counts.warning // 0' "$dir/live_check.json")
              S=$(jq -r '.sample_count // 0' "$dir/live_check.json")

              TOTAL_VIOLATIONS=$((TOTAL_VIOLATIONS + V))
              TOTAL_WARNINGS=$((TOTAL_WARNINGS + W))
              TOTAL_SAMPLES=$((TOTAL_SAMPLES + S))
            fi
          done

          echo "## 📊 Aggregate Results" >> $GITHUB_STEP_SUMMARY
          echo "" >> $GITHUB_STEP_SUMMARY
          echo "| Metric | Total |" >> $GITHUB_STEP_SUMMARY
          echo "|--------|-------|" >> $GITHUB_STEP_SUMMARY
          echo "| Violations | ${TOTAL_VIOLATIONS} |" >> $GITHUB_STEP_SUMMARY
          echo "| Warnings | ${TOTAL_WARNINGS} |" >> $GITHUB_STEP_SUMMARY

      await github.rest.issues.createComment({
        issue_number: context.issue.number,
        owner: context.repo.owner,
        repo: context.repo.repo,
        body: fixInstructions
      });
```

#### Timeout

**Symptom:**
```
Error: Process timeout after 120s
```

**Recovery:**
```yaml
- name: Run tests with extended timeout
  timeout-minutes: 15  # Increased from 10
  run: |
    cargo test --features otel --workspace
```

### 3. Network Issues

#### OTLP Collector Unreachable

**Symptom:**
```
Error: Connection refused (localhost:4317)
```

**Detection & Retry:**
```yaml
- name: Wait for OTLP collector
  run: |
    max_attempts=10
    attempt=0

    while [ $attempt -lt $max_attempts ]; do
      if nc -z localhost 4317; then
        echo "✅ OTLP collector ready"
        exit 0
      fi

      attempt=$((attempt + 1))
      echo "Waiting for collector (attempt $attempt/$max_attempts)..."
      sleep 2
    done

    echo "::error::OTLP collector did not become ready"
    exit 1
```

### 4. Zero Telemetry Detection (Critical)

**Symptom:**
```json
{
  "sample_count": 0
}
```

**This is a FALSE POSITIVE indicator** - tests pass but no telemetry was emitted!

**Detection:**
```yaml
- name: Check for zero telemetry (critical)
  run: |
    SAMPLES=$(jq -r '.sample_count // 0' validation_output/live_check.json)

    if [ "$SAMPLES" -eq 0 ]; then
      echo "::error::CRITICAL: Zero telemetry samples received"
      echo "::error::Tests may be passing with false positives!"
      echo ""
      echo "Diagnostic checklist:"
      echo "- OTEL_EXPORTER_OTLP_ENDPOINT set correctly?"
      echo "- Telemetry initialized in tests?"
      echo "- OTLP collector running?"
      echo "- Network connectivity between test and collector?"
      exit 1
    fi
```

## Troubleshooting Runbook

### Common Issues

#### Issue 1: "Weaver health check timeout"

**Symptom:**
```
❌ Weaver health check timeout after 30s
```

**Diagnosis:**
```bash
# Check if Weaver is running
ps aux | grep weaver

# Check port binding
lsof -i :8080

# Check logs
cat validation_output/weaver.log
```

**Solutions:**

1. **Increase timeout:**
```yaml
max_wait=60  # Increase from 30s
```

2. **Check admin port:**
```bash
# Verify admin port is accessible
curl -v http://localhost:8080/health
```

3. **Check firewall:**
```bash
# Test connectivity
nc -zv localhost 8080
```

#### Issue 2: "Zero telemetry samples received"

**Symptom:**
```json
{
  "sample_count": 0
}
```

**Diagnosis:**
```bash
# Check OTLP endpoint
echo $OTEL_EXPORTER_OTLP_ENDPOINT

# Verify collector is running
curl http://localhost:13133/  # Collector health

# Check Weaver listener
netstat -an | grep 4317
```

**Solutions:**

1. **Verify OTLP endpoint:**
```bash
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
```

2. **Check telemetry init:**
```rust
// Ensure telemetry is initialized
#[cfg(feature = "otel")]
let _guard = clnrm_core::telemetry::init_otel(config)?;
```

3. **Test connectivity:**
```bash
# Send test span
grpcurl -plaintext -d '{"resourceSpans":[]}' \
  localhost:4317 \
  opentelemetry.proto.collector.trace.v1.TraceService/Export
```

#### Issue 3: "Port already in use"

**Symptom:**
```
Error: Address already in use (port 4317)
```

**Diagnosis:**
```bash
# Find process using port
lsof -i :4317

# Check all OTLP ports
lsof -i :4317-4347
```

**Solutions:**

1. **Kill existing process:**
```bash
kill -9 $(lsof -t -i:4317)
```

2. **Use dynamic port:**
```bash
OTLP_PORT=$(python3 -c 'import socket; s=socket.socket(); s.bind(("", 0)); print(s.getsockname()[1]); s.close()')
```

3. **Wait for port release:**
```bash
while lsof -i :4317 >/dev/null 2>&1; do
  sleep 1
done
```

#### Issue 4: "Schema validation failed"

**Symptom:**
```
❌ Schema validation FAILED
Error: Invalid attribute definition
```

**Diagnosis:**
```bash
# Validate schemas
weaver registry check --registry registry/ --debug --debug

# Check for syntax errors
yamllint registry/*.yaml
```

**Solutions:**

1. **Fix schema syntax:**
```yaml
# Bad
attributes:
  - id: my-attribute  # Hyphens not allowed

# Good
attributes:
  - id: my_attribute
```

2. **Validate incrementally:**
```bash
# Validate one schema at a time
for schema in registry/*.yaml; do
  echo "Checking $schema"
  weaver registry check --registry $(dirname $schema)
done
```

#### Issue 5: "Violations detected"

**Symptom:**
```
❌ Weaver detected 5 violations
```

**Diagnosis:**
```bash
# Extract violation details
jq -r '.advices[] | select(.advice_level == "violation") |
       "\(.signal_type): \(.message)"' \
  validation_output/live_check.json
```

**Solutions:**

1. **Missing attributes:**
```rust
// Add missing attribute
span.set_attribute("container.id", container_id);
```

2. **Type mismatches:**
```rust
// Fix type
span.set_attribute("exit_code", exit_code as i64);  // Not string
```

3. **Check schema:**
```yaml
# Ensure attribute is defined
attributes:
  - id: container.id
    type: string
    requirement_level: required
```
