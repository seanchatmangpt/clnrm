## Executive Summary

This document specifies the complete diagnostic output integration system for clnrm v1.3.0's Weaver live-check feature. The system supports three output formats (ANSI, JSON, GitHub Workflow Commands), automatic format detection, TOML configuration, and production-grade error handling.

**Key Features**:
- Multi-format output (ANSI/JSON/GitHub Actions)
- Automatic CI/CD detection
- Enhanced clnrm context integration
- Zero-copy streaming for performance
- Comprehensive error handling
- Full schema validation

## 4. Format Auto-Detection Algorithm

```rust
pub enum DiagnosticFormat {
    Ansi,
    Json,
    GithubWorkflow,
}

pub struct FormatDetector;

impl FormatDetector {
    /// Detect appropriate format based on environment
    pub fn auto_detect(config: &DiagnosticConfig) -> DiagnosticFormat {
        // 1. Check explicit configuration
        if let Some(format) = config.explicit_format {
            return format;
        }

        // 2. Check environment variables
        if let Ok(format_str) = std::env::var("CLNRM_DIAGNOSTIC_FORMAT") {
            if let Ok(format) = DiagnosticFormat::from_str(&format_str) {
                return format;
            }
        }

        // 3. Detect CI/CD environments
        if Self::is_github_actions() {
            return DiagnosticFormat::GithubWorkflow;
        }

        if Self::is_ci_environment() {
            // Generic CI: use JSON
            return DiagnosticFormat::Json;
        }

        // 4. Check if stdout is a TTY
        if atty::is(atty::Stream::Stdout) {
            return DiagnosticFormat::Ansi;
        }

        // 5. Default: JSON for non-interactive
        DiagnosticFormat::Json
    }

    /// Detect GitHub Actions environment
    fn is_github_actions() -> bool {
        std::env::var("GITHUB_ACTIONS").map(|v| v == "true").unwrap_or(false)
    }

    /// Detect generic CI environment
    fn is_ci_environment() -> bool {
        std::env::var("CI").is_ok()
            || std::env::var("CONTINUOUS_INTEGRATION").is_ok()
            || std::env::var("BUILD_ID").is_ok()
    }
}
```

### Detection Flow

```
┌─────────────────────────────────────┐
│   Auto-Detection Decision Tree      │
└─────────────────────────────────────┘

CLI flag --format?
  ├─ Yes → Use specified format
  └─ No ↓

CLNRM_DIAGNOSTIC_FORMAT env var?
  ├─ Yes → Use env var format
  └─ No ↓

GITHUB_ACTIONS=true?
  ├─ Yes → GithubWorkflow
  └─ No ↓

CI=true or BUILD_ID set?
  ├─ Yes → Json
  └─ No ↓

stdout is TTY?
  ├─ Yes → Ansi
  └─ No → Json
```

## 5. Processing Pipeline Design

### Pipeline Stages

```rust
use serde::{Deserialize, Serialize};
use std::process::{Command, Stdio};
use tokio::io::{AsyncBufReadExt, BufReader};

/// Complete diagnostic processing pipeline
pub struct DiagnosticPipeline {
    config: DiagnosticConfig,
    weaver_process: WeaverProcess,
    formatters: FormatterRegistry,
}

impl DiagnosticPipeline {
    /// Execute full pipeline: capture → parse → enrich → format → output
    pub async fn execute(
        &mut self,
        test_context: &TestContext,
    ) -> Result<DiagnosticResult, DiagnosticError> {
        // Stage 1: Capture Weaver output
        let raw_output = self.capture_weaver_output().await?;

        // Stage 2: Parse Weaver report
        let weaver_report = self.parse_weaver_output(&raw_output)?;

        // Stage 3: Enrich with clnrm context
        let enriched_report = self.enrich_with_context(weaver_report, test_context)?;

        // Stage 4: Select format
        let format = self.select_format();

        // Stage 5: Transform to target format
        let formatted_output = self.format_output(&enriched_report, format)?;

        // Stage 6: Output to destinations
        self.write_outputs(&formatted_output).await?;

        // Stage 7: Determine exit code
        let exit_code = self.map_to_exit_code(&enriched_report)?;

        Ok(DiagnosticResult {
            report: enriched_report,
            exit_code,
            output_paths: self.get_output_paths(),
        })
    }

    /// Stage 1: Capture stdout/stderr from Weaver process
    async fn capture_weaver_output(&mut self) -> Result<RawOutput, DiagnosticError> {
        let mut child = self.weaver_process.spawn()?;

        let stdout = child.stdout.take()
            .ok_or(DiagnosticError::MissingStdout)?;
        let stderr = child.stderr.take()
            .ok_or(DiagnosticError::MissingStderr)?;

        // Stream both stdout and stderr concurrently
        let stdout_lines = Self::read_stream(stdout);
        let stderr_lines = Self::read_stream(stderr);

        let (stdout_result, stderr_result) = tokio::join!(stdout_lines, stderr_lines);

        let exit_status = child.wait().await?;

        Ok(RawOutput {
            stdout: stdout_result?,
            stderr: stderr_result?,
            exit_code: exit_status.code(),
        })
    }

    /// Read stream line-by-line (zero-copy where possible)
    async fn read_stream<R: tokio::io::AsyncRead + Unpin>(
        stream: R,
    ) -> Result<Vec<String>, std::io::Error> {
        let reader = BufReader::new(stream);
        let mut lines = reader.lines();
        let mut output = Vec::new();

        while let Some(line) = lines.next_line().await? {
            output.push(line);
        }

        Ok(output)
    }

    /// Stage 2: Parse Weaver output into structured report
    fn parse_weaver_output(&self, raw: &RawOutput) -> Result<WeaverReport, DiagnosticError> {
        // Detect Weaver output format (could be ANSI, JSON, or plain text)
        let format = self.detect_weaver_format(&raw.stdout)?;

        match format {
            WeaverOutputFormat::Json => {
                serde_json::from_str(&raw.stdout.join("\n"))
                    .map_err(DiagnosticError::JsonParse)?
            }
            WeaverOutputFormat::Ansi => {
                // Parse ANSI format using regex/manual parsing
                self.parse_ansi_format(&raw.stdout)?
            }
        }
    }

    /// Stage 3: Enrich Weaver report with clnrm context
    fn enrich_with_context(
        &self,
        weaver_report: WeaverReport,
        test_context: &TestContext,
    ) -> Result<EnrichedReport, DiagnosticError> {
        Ok(EnrichedReport {
            // clnrm metadata
            clnrm_version: env!("CARGO_PKG_VERSION").to_string(),
            test_name: test_context.name.clone(),
            test_file: test_context.config_path.clone(),
            timestamp: chrono::Utc::now(),
            execution_duration_ms: test_context.execution_duration.as_millis() as u64,

            // Weaver report (original)
            weaver_report,

            // clnrm analysis
            analysis: self.analyze_violations(&weaver_report)?,

            // Environment info
            environment: EnvironmentInfo {
                os: std::env::consts::OS.to_string(),
                arch: std::env::consts::ARCH.to_string(),
                ci: FormatDetector::is_ci_environment(),
                github_actions: FormatDetector::is_github_actions(),
            },
        })
    }

    /// Stage 4: Select output format
    fn select_format(&self) -> DiagnosticFormat {
        FormatDetector::auto_detect(&self.config)
    }

    /// Stage 5: Format output
    fn format_output(
        &self,
        report: &EnrichedReport,
        format: DiagnosticFormat,
    ) -> Result<FormattedOutput, DiagnosticError> {
        let formatter = self.formatters.get(format)?;
        formatter.format(report)
    }

    /// Stage 6: Write to all configured destinations
    async fn write_outputs(&self, output: &FormattedOutput) -> Result<(), DiagnosticError> {
        let mut tasks = Vec::new();

        // Write to stdout
        if self.config.stdout {
            tasks.push(tokio::spawn(async move {
                println!("{}", output.content);
            }));
        }

        // Write to file
        if let Some(path) = &self.config.output_file {
            let content = output.content.clone();
            let path = path.clone();
            tasks.push(tokio::spawn(async move {
                tokio::fs::write(&path, content).await
            }));
        }

        // Upload to GitHub artifact
        if self.config.github_artifact && FormatDetector::is_github_actions() {
            tasks.push(self.upload_github_artifact(output));
        }

        // Wait for all outputs to complete
        for task in tasks {
            task.await??;
        }

        Ok(())
    }

    /// Stage 7: Map violations to exit code
    fn map_to_exit_code(&self, report: &EnrichedReport) -> Result<i32, DiagnosticError> {
        let violations = &report.analysis;

        if self.config.fail_on_violation && violations.critical_violations > 0 {
            return Ok(1); // Critical violations → exit 1
        }

        if self.config.fail_on_missing_optional && violations.optional_violations > 0 {
            return Ok(2); // Optional violations → exit 2
        }

        Ok(0) // Success
    }
}

/// Stage-specific data structures
#[derive(Debug)]
struct RawOutput {
    stdout: Vec<String>,
    stderr: Vec<String>,
    exit_code: Option<i32>,
}

#[derive(Debug, Clone)]
pub struct DiagnosticResult {
    pub report: EnrichedReport,
    pub exit_code: i32,
    pub output_paths: Vec<PathBuf>,
}
```

```rust
use colored::Colorize;

/// ANSI formatter for terminal output
pub struct AnsiFormatter {
    config: AnsiConfig,
}

impl DiagnosticFormatter for AnsiFormatter {
    fn format(&self, report: &EnrichedReport) -> Result<FormattedOutput, DiagnosticError> {
        let mut output = String::new();

        // Header
        if self.config.show_header {
            output.push_str(&self.format_header(report));
        }

        // Conformance summary
        output.push_str(&self.format_conformance_summary(&report.weaver_report));

        // Critical violations
        if report.analysis.critical_violations > 0 {
            output.push_str(&self.format_violations(&report.weaver_report.violations));
        }

        // Optional warnings
        if !report.weaver_report.warnings.is_empty() {
            output.push_str(&self.format_warnings(&report.weaver_report.warnings));
        }

        // Recommendation
        output.push_str(&self.format_recommendation(&report.analysis));

        // Footer
        output.push_str(&self.format_footer());

        Ok(FormattedOutput {
            content: output,
            format: DiagnosticFormat::Ansi,
            size_bytes: output.len(),
        })
    }

    fn file_extension(&self) -> &str { "txt" }
    fn mime_type(&self) -> &str { "text/plain" }
}

impl AnsiFormatter {
    fn format_header(&self, report: &EnrichedReport) -> String {
        let mut s = String::new();

        s.push_str("╔════════════════════════════════════════════════════════════╗\n");
        s.push_str("║                  clnrm Weaver Live Check                   ║\n");
        s.push_str(&format!("║                      v{} Report                         ║\n",
            report.clnrm_version));
        s.push_str("╚════════════════════════════════════════════════════════════╝\n\n");

        s.push_str(&format!("Test: {}\n", report.test_name));
        s.push_str(&format!("File: {}\n", report.test_file.display()));
        s.push_str(&format!("Time: {}\n", report.timestamp.format("%Y-%m-%d %H:%M:%S UTC")));
        s.push_str(&format!("Duration: {}ms\n\n", report.execution_duration_ms));

        s
    }

    fn format_conformance_summary(&self, weaver: &WeaverReport) -> String {
        let mut s = String::new();

        s.push_str("┌────────────────────────────────────────────────────────────┐\n");
        s.push_str("│                  Conformance Summary                        │\n");
        s.push_str("└────────────────────────────────────────────────────────────┘\n\n");

        // Spans
        let spans = &weaver.conformance.spans;
        let spans_icon = if spans.missing == 0 { "✅" } else { "❌" };
        s.push_str(&format!("{} Spans: {}/{} ({:.1}%)\n",
            spans_icon, spans.present, spans.required, spans.percentage));

        // Attributes
        let attrs = &weaver.conformance.attributes;
        let attrs_icon = if attrs.missing == 0 { "✅" } else { "⚠️" };
        s.push_str(&format!("{} Attributes: {}/{} ({:.1}%)\n",
            attrs_icon, attrs.present, attrs.required, attrs.percentage));

        // Metrics
        let metrics = &weaver.conformance.metrics;
        let metrics_icon = if metrics.missing == 0 { "✅" } else { "❌" };
        s.push_str(&format!("{} Metrics: {}/{} ({:.1}%)\n",
            metrics_icon, metrics.present, metrics.required, metrics.percentage));

        // Events
        let events = &weaver.conformance.events;
        let events_icon = if events.missing == 0 { "✅" } else { "❌" };
        s.push_str(&format!("{} Events: {}/{} ({:.1}%)\n\n",
            events_icon, events.present, events.required, events.percentage));

        s
    }

    fn format_violations(&self, violations: &[Violation]) -> String {
        let mut s = String::new();

        s.push_str("┌────────────────────────────────────────────────────────────┐\n");
        s.push_str("│                   Critical Violations                       │\n");
        s.push_str("└────────────────────────────────────────────────────────────┘\n\n");

        for (i, violation) in violations.iter().enumerate() {
            s.push_str(&format!("❌ {}\n", violation.name.red().bold()));
            s.push_str(&format!("   Schema: {}:{}\n",
                violation.schema_file.display(), violation.schema_line));
            s.push_str(&format!("   Severity: {}\n", "ERROR".red()));
            s.push_str(&format!("\n   {}\n\n", violation.message));

            if self.config.show_docs_links {
                if let Some(url) = &violation.documentation_url {
                    s.push_str(&format!("   📖 Documentation: {}\n", url.blue().underline()));
                }
            }

            if i < violations.len() - 1 {
                s.push('\n');
            }
        }

        s.push('\n');
        s
    }
}

pub struct GithubWorkflowFormatter {
    config: GithubConfig,
}

impl DiagnosticFormatter for GithubWorkflowFormatter {
    fn format(&self, report: &EnrichedReport) -> Result<FormattedOutput, DiagnosticError> {
        let mut output = String::new();

        // Group: Header
        output.push_str("::group::clnrm Weaver Live Check Report\n");
        output.push_str(&format!("Test: {}\n", report.test_name));
        output.push_str(&format!("File: {}\n", report.test_file.display()));
        output.push_str(&format!("Time: {}\n", report.timestamp.format("%Y-%m-%d %H:%M:%S UTC")));
        output.push_str(&format!("Duration: {}ms\n", report.execution_duration_ms));
        output.push_str("::endgroup::\n\n");

        // Group: Conformance summary
        output.push_str("::group::Conformance Summary\n");
        let weaver = &report.weaver_report;
        output.push_str(&format!("✅ Spans: {}/{} ({:.1}%)\n",
            weaver.conformance.spans.present,
            weaver.conformance.spans.required,
            weaver.conformance.spans.percentage));
        output.push_str("::endgroup::\n\n");

        // Violations as error annotations
        for violation in &weaver.violations {
            let level = &self.config.critical_level;
            if self.config.include_file_paths {
                output.push_str(&format!(
                    "::{} file={},line={},title={}::{}\n",
                    level,
                    violation.schema_file.display(),
                    violation.schema_line,
                    violation.name,
                    violation.message
                ));
            } else {
                output.push_str(&format!(
                    "::{} title={}::{}\n",
                    level, violation.name, violation.message
                ));
            }
        }

        // Warnings
        for warning in &weaver.warnings {
            let level = &self.config.optional_level;
            output.push_str(&format!(
                "::{} file={},line={},title={}::{}\n",
                level,
                warning.schema_file.display(),
                warning.schema_line,
                warning.name,
                warning.message
            ));
        }

        // Set outputs for downstream jobs
        output.push_str(&format!("::set-output name=conformance_score::{}\n",
            report.analysis.conformance_score));
        output.push_str(&format!("::set-output name=critical_violations::{}\n",
            report.analysis.critical_violations));
        output.push_str(&format!("::set-output name=exit_code::{}\n",
            report.analysis.exit_code));

        Ok(FormattedOutput {
            content: output,
            format: DiagnosticFormat::GithubWorkflow,
            size_bytes: output.len(),
        })
    }

    fn file_extension(&self) -> &str { "txt" }
    fn mime_type(&self) -> &str { "text/plain" }
}
```

```rust
use std::collections::HashMap;

pub struct FormatterRegistry {
    formatters: HashMap<DiagnosticFormat, Box<dyn DiagnosticFormatter>>,
}

impl FormatterRegistry {
    pub fn new(config: &DiagnosticConfig) -> Self {
        let mut formatters: HashMap<DiagnosticFormat, Box<dyn DiagnosticFormatter>> = HashMap::new();

        formatters.insert(
            DiagnosticFormat::Ansi,
            Box::new(AnsiFormatter { config: config.ansi.clone() }),
        );

        formatters.insert(
            DiagnosticFormat::Json,
            Box::new(JsonFormatter { config: config.json.clone() }),
        );

        formatters.insert(
            DiagnosticFormat::GithubWorkflow,
            Box::new(GithubWorkflowFormatter { config: config.github.clone() }),
        );

        Self { formatters }
    }

    pub fn get(&self, format: DiagnosticFormat) -> Result<&dyn DiagnosticFormatter, DiagnosticError> {
        self.formatters
            .get(&format)
            .map(|f| f.as_ref())
            .ok_or(DiagnosticError::UnsupportedFormat(format))
    }
}
```

```rust
use thiserror::Error;

#[derive(Debug, Error)]
pub enum DiagnosticError {
    #[error("Failed to spawn Weaver process: {0}")]
    ProcessSpawn(#[from] std::io::Error),

    #[error("Weaver process stdout not captured")]
    MissingStdout,

    #[error("Weaver process stderr not captured")]
    MissingStderr,

    #[error("Weaver process exited with code {0}")]
    WeaverExitCode(i32),

    #[error("Failed to parse Weaver JSON output: {0}")]
    JsonParse(#[from] serde_json::Error),

    #[error("Failed to parse Weaver ANSI output: {0}")]
    AnsiParse(String),

    #[error("Unknown Weaver output format")]
    UnknownFormat,

    #[error("Unsupported diagnostic format: {0:?}")]
    UnsupportedFormat(DiagnosticFormat),

    #[error("Failed to write output file: {0}")]
    FileWrite(std::io::Error),

    #[error("Failed to upload GitHub artifact: {0}")]
    GithubArtifact(String),

    #[error("Configuration error: {0}")]
    Config(String),

    #[error("Invalid exit code mapping: {0}")]
    InvalidExitCode(String),
}

impl From<DiagnosticError> for crate::error::CleanroomError {
    fn from(err: DiagnosticError) -> Self {
        crate::error::CleanroomError::internal_error(err.to_string())
    }
}
```

### Error Recovery Strategies

| Error Type | Recovery Strategy | User Impact |
|------------|------------------|-------------|
| `ProcessSpawn` | Retry once, then fail with instructions | Critical - test fails |
| `MissingStdout` | Fall back to stderr parsing | Low - degrade gracefully |
| `WeaverExitCode` | Log error, continue with partial report | Medium - warn user |
| `JsonParse` | Try ANSI parser, then fail | Medium - degrade format |
| `AnsiParse` | Return raw output with warning | Low - show raw |
| `FileWrite` | Log error, continue to stdout | Low - continue |
| `GithubArtifact` | Log warning, don't fail test | Low - CI continues |

## Appendix B: Configuration Validation

```rust
impl DiagnosticConfig {
    /// Validate configuration after loading from TOML
    pub fn validate(&self) -> Result<(), DiagnosticError> {
        // Validate format
        match self.format.as_str() {
            "auto" | "ansi" | "json" | "gh_workflow" => {},
            other => return Err(DiagnosticError::Config(
                format!("Invalid format: '{}'. Must be 'auto', 'ansi', 'json', or 'gh_workflow'", other)
            )),
        }

        // Validate output file path
        if let Some(path) = &self.output_file {
            if let Some(parent) = PathBuf::from(path).parent() {
                if !parent.exists() {
                    return Err(DiagnosticError::Config(
                        format!("Output directory does not exist: {}", parent.display())
                    ));
                }
            }
        }

        // Validate ANSI config
        if self.ansi.verbosity > 2 {
            return Err(DiagnosticError::Config(
                "ANSI verbosity must be 0, 1, or 2".into()
            ));
        }

        // Validate GitHub config
        match self.github.critical_level.as_str() {
            "error" | "warning" | "notice" => {},
            other => return Err(DiagnosticError::Config(
                format!("Invalid critical_level: '{}'. Must be 'error', 'warning', or 'notice'", other)
            )),
        }

        match self.github.optional_level.as_str() {
            "error" | "warning" | "notice" => {},
            other => return Err(DiagnosticError::Config(
                format!("Invalid optional_level: '{}'. Must be 'error', 'warning', or 'notice'", other)
            )),
        }

        Ok(())
    }
}
```
