### 2.2 Initialization Integration

**Before Test Execution:**

```rust
pub async fn initialize_test_execution(
    config: &TestConfig,
    cli_args: &CliArgs,
) -> Result<TestExecutionContext> {
    // 1. Determine if live-check should be used
    let use_live_check = should_use_live_check(config, cli_args)?;

    if use_live_check {
        // 2. Validate prerequisites
        validate_weaver_prerequisites(config)?;

        // 3. Create orchestrator
        let orchestrator = LiveCheckOrchestrator::new(config.clone())?;

        // 4. Start Weaver
        let orchestrator = orchestrator.start_weaver().await?;

        // 5. Get OTLP endpoint
        let otlp_endpoint = orchestrator.get_otlp_endpoint()?;

        // 6. Initialize OTEL with Weaver endpoint
        let otel_guard = init_otel_with_weaver(config, &otlp_endpoint)?;

        Ok(TestExecutionContext::WithLiveCheck {
            orchestrator,
            otel_guard,
        })
    } else {
        // v1.2.1 flow
        let otel_guard = init_otel_legacy(config)?;

        Ok(TestExecutionContext::Legacy {
            otel_guard,
        })
    }
}

fn validate_weaver_prerequisites(config: &TestConfig) -> Result<()> {
    let live_check = config.live_check.as_ref()
        .ok_or_else(|| CleanroomError::config_error("live_check not configured"))?;

    // 1. Check weaver binary exists
    let weaver_path = which::which("weaver")
        .map_err(|_| CleanroomError::dependency_error(
            "weaver binary not found. Install with: cargo install weaver-cli"
        ))?;

    tracing::info!("Found weaver binary", path = ?weaver_path);

    // 2. Validate registry path exists
    let registry_path = PathBuf::from(&live_check.registry_path);
    if !registry_path.exists() {
        return Err(CleanroomError::config_error(
            format!("Registry path not found: {}", live_check.registry_path)
        ));
    }

    // 3. Check if registry has schemas
    let schema_count = count_schemas(&registry_path)?;
    if schema_count == 0 {
        return Err(CleanroomError::config_error(
            format!("No schemas found in registry: {}", live_check.registry_path)
        ));
    }

    tracing::info!("Registry validation passed",
        path = ?registry_path,
        schema_count = schema_count
    );

    // 4. Check port availability
    if live_check.otlp_port != 0 {
        check_port_available(live_check.otlp_port)?;
    }
    if live_check.admin_port != 0 {
        check_port_available(live_check.admin_port)?;
    }

    Ok(())
}

fn check_port_available(port: u16) -> Result<()> {
    use std::net::TcpListener;

    TcpListener::bind(("127.0.0.1", port))
        .map_err(|e| CleanroomError::config_error(
            format!("Port {} unavailable: {}", port, e)
        ))?;

    Ok(())
}

fn count_schemas(registry_path: &Path) -> Result<usize> {
    let mut count = 0;

    for entry in walkdir::WalkDir::new(registry_path)
        .follow_links(true)
        .into_iter()
        .filter_map(|e| e.ok())
    {
        if entry.path().extension().and_then(|s| s.to_str()) == Some("yaml") {
            count += 1;
        }
    }

    Ok(count)
}
```

### 2.3 OTEL Initialization Integration

**Dynamic Endpoint Configuration:**

```rust
fn init_otel_with_weaver(
    config: &TestConfig,
    otlp_endpoint: &str,
) -> Result<OtelGuard> {
    use opentelemetry::trace::TracerProvider;
    use opentelemetry_sdk::trace::{self, Sampler};
    use opentelemetry_otlp::WithExportConfig;

    let otel_config = config.otel.as_ref()
        .ok_or_else(|| CleanroomError::config_error("OTEL config missing"))?;

    // 1. Configure OTLP exporter to Weaver
    let exporter = opentelemetry_otlp::new_exporter()
        .http()
        .with_endpoint(otlp_endpoint)
        .with_timeout(Duration::from_secs(5))
        .build_span_exporter()
        .map_err(|e| CleanroomError::internal_error(
            format!("Failed to create OTLP exporter: {}", e)
        ))?;

    // 2. Create tracer provider with batch processor
    let tracer_provider = trace::TracerProvider::builder()
        .with_batch_exporter(
            exporter,
            opentelemetry_sdk::runtime::Tokio,
        )
        .with_sampler(Sampler::ParentBased(Box::new(
            Sampler::TraceIdRatioBased(otel_config.sample_ratio)
        )))
        .with_resource(opentelemetry_sdk::Resource::new(vec![
            opentelemetry::KeyValue::new("service.name", otel_config.service_name.clone()),
            opentelemetry::KeyValue::new("deployment.environment", "test"),
            opentelemetry::KeyValue::new("clnrm.version", env!("CARGO_PKG_VERSION")),
        ]))
        .build();

    // 3. Set as global provider
    let tracer = tracer_provider.tracer("clnrm");
    opentelemetry::global::set_tracer_provider(tracer_provider.clone());

    tracing::info!("OTEL initialized with Weaver", endpoint = otlp_endpoint);

    Ok(OtelGuard {
        tracer_provider: Some(tracer_provider),
    })
}

pub struct OtelGuard {
    tracer_provider: Option<opentelemetry_sdk::trace::TracerProvider>,
}

impl Drop for OtelGuard {
    fn drop(&mut self) {
        if let Some(provider) = self.tracer_provider.take() {
            // Flush and shutdown
            if let Err(e) = provider.shutdown() {
                tracing::error!("Failed to shutdown OTEL: {}", e);
            }
        }
    }
}
```

### 2.4 Test Execution Integration

**Span Emission During Execution:**

```rust
pub async fn execute_test_with_telemetry(
    env: &CleanroomEnvironment,
    config: &TestConfig,
    context: &TestExecutionContext,
) -> Result<TestResult> {
    use opentelemetry::trace::Tracer;

    let tracer = opentelemetry::global::tracer("clnrm");

    // 1. Start test execution span
    let mut test_span = tracer
        .span_builder("clnrm.test.execute")
        .with_attributes(vec![
            opentelemetry::KeyValue::new("test.name", config.metadata.name.clone()),
            opentelemetry::KeyValue::new("test.hermetic", true),
            opentelemetry::KeyValue::new("test.step_count", config.steps.len() as i64),
        ])
        .start(&tracer);

    let test_start = std::time::Instant::now();
    let mut result = TestResult::default();

    // 2. Execute steps with span propagation
    for (idx, step) in config.steps.iter().enumerate() {
        let step_result = execute_step_with_span(
            env,
            step,
            idx,
            &tracer,
        ).await?;

        result.step_results.push(step_result);
    }

    // 3. Record test completion
    let duration = test_start.elapsed();
    test_span.set_attribute(
        opentelemetry::KeyValue::new("test.duration_ms", duration.as_millis() as i64)
    );
    test_span.set_attribute(
        opentelemetry::KeyValue::new("test.passed", result.all_steps_passed())
    );

    test_span.end();

    // 4. Flush if using live-check
    if matches!(context, TestExecutionContext::WithLiveCheck { .. }) {
        flush_otel_buffers().await?;
    }

    Ok(result)
}

async fn execute_step_with_span(
    env: &CleanroomEnvironment,
    step: &StepConfig,
    step_index: usize,
    tracer: &opentelemetry_sdk::trace::Tracer,
) -> Result<StepResult> {
    let mut span = tracer
        .span_builder("clnrm.step.execute")
        .with_attributes(vec![
            opentelemetry::KeyValue::new("step.name", step.name.clone()),
            opentelemetry::KeyValue::new("step.index", step_index as i64),
            opentelemetry::KeyValue::new("step.command", step.command.join(" ")),
        ])
        .start(tracer);

    // Execute step
    let result = env.execute_step(step).await;

    // Record result in span
    match &result {
        Ok(step_result) => {
            span.set_attribute(
                opentelemetry::KeyValue::new("step.passed", step_result.passed)
            );
            if let Some(output) = &step_result.output {
                span.set_attribute(
                    opentelemetry::KeyValue::new("step.output_length", output.len() as i64)
                );
            }
        }
        Err(e) => {
            span.set_attribute(
                opentelemetry::KeyValue::new("step.error", e.to_string())
            );
            span.set_status(
                opentelemetry::trace::Status::error(e.to_string())
            );
        }
    }

    span.end();
    result
}

async fn flush_otel_buffers() -> Result<()> {
    tracing::info!("Flushing OTEL buffers");

    // Shutdown global tracer provider (triggers flush)
    opentelemetry::global::shutdown_tracer_provider();

    // Wait for delivery (batch processor has 5s timeout by default)
    tokio::time::sleep(Duration::from_millis(500)).await;

    tracing::info!("OTEL buffers flushed");
    Ok(())
}
```

### 2.5 Post-Execution Integration

**Conformance Report Parsing:**

```rust
pub async fn finalize_test_execution(
    mut context: TestExecutionContext,
    test_result: TestResult,
) -> Result<FinalTestResult> {
    match context {
        TestExecutionContext::WithLiveCheck {
            mut orchestrator,
            otel_guard,
        } => {
            // 1. Ensure OTEL flushed (should already be done)
            drop(otel_guard);

            // 2. Stop Weaver (generates conformance report)
            tracing::info!("Stopping Weaver to generate conformance report");
            let orchestrator = orchestrator.stop_weaver().await?;

            // 3. Parse conformance report
            let conformance = orchestrator.get_conformance_report()?;

            // 4. Combine test result + conformance
            let final_result = FinalTestResult {
                test_passed: test_result.all_steps_passed(),
                conformance_passed: conformance.is_conformant(),
                test_result,
                conformance_report: Some(conformance),
            };

            Ok(final_result)
        }
        TestExecutionContext::Legacy { otel_guard } => {
            // v1.2.1 flow - no conformance
            drop(otel_guard);

            Ok(FinalTestResult {
                test_passed: test_result.all_steps_passed(),
                conformance_passed: true,  // N/A
                test_result,
                conformance_report: None,
            })
        }
    }
}

#[derive(Debug, Clone)]
pub struct FinalTestResult {
    pub test_passed: bool,
    pub conformance_passed: bool,
    pub test_result: TestResult,
    pub conformance_report: Option<ConformanceReport>,
}

impl FinalTestResult {
    pub fn overall_passed(&self) -> bool {
        self.test_passed && self.conformance_passed
    }

    pub fn exit_code(&self) -> i32 {
        if self.overall_passed() {
            0
        } else {
            1
        }
    }

    pub fn summary(&self) -> String {
        match (self.test_passed, self.conformance_passed) {
            (true, true) => "✅ Test passed, schema conformance passed".to_string(),
            (true, false) => "❌ Test passed, but schema conformance FAILED".to_string(),
            (false, true) => "❌ Test FAILED, schema conformance passed".to_string(),
            (false, false) => "❌ Test FAILED, schema conformance FAILED".to_string(),
        }
    }
}
```

### 3.2 Graceful Degradation

**Principle:** Weaver failures should NOT block test execution (unless explicitly required).

```rust
async fn initialize_with_graceful_fallback(
    config: &TestConfig,
    cli_args: &CliArgs,
) -> Result<TestExecutionContext> {
    let use_live_check = should_use_live_check(config, cli_args)?;

    if use_live_check {
        match try_initialize_live_check(config).await {
            Ok(context) => {
                tracing::info!("✅ Live-check enabled successfully");
                return Ok(context);
            }
            Err(e) => {
                // Check if live-check is REQUIRED
                let required = config.live_check.as_ref()
                    .and_then(|lc| lc.required)
                    .unwrap_or(false);

                if required {
                    // Fail fast if required
                    return Err(CleanroomError::from(e));
                } else {
                    // Log warning and fall back
                    tracing::warn!(
                        "⚠️  Live-check initialization failed, falling back to legacy mode",
                        error = %e,
                        suggestion = "Check weaver installation: cargo install weaver-cli"
                    );

                    return initialize_legacy_mode(config);
                }
            }
        }
    } else {
        initialize_legacy_mode(config)
    }
}

async fn try_initialize_live_check(
    config: &TestConfig,
) -> std::result::Result<TestExecutionContext, LiveCheckError> {
    // 1. Validate prerequisites
    validate_weaver_prerequisites(config)
        .map_err(|e| LiveCheckError::RegistryValidation(e.to_string()))?;

    // 2. Create orchestrator
    let orchestrator = LiveCheckOrchestrator::new(config.clone())
        .map_err(|e| LiveCheckError::WeaverStartup(e.to_string()))?;

    // 3. Start Weaver with timeout
    let orchestrator = tokio::time::timeout(
        Duration::from_secs(10),
        orchestrator.start_weaver()
    )
    .await
    .map_err(|_| LiveCheckError::WeaverTimeout("Weaver startup exceeded 10s".to_string()))?
    .map_err(|e| LiveCheckError::WeaverStartup(e.to_string()))?;

    // 4. Get OTLP endpoint
    let otlp_endpoint = orchestrator.get_otlp_endpoint()
        .map_err(|e| LiveCheckError::OtlpConnection(e.to_string()))?;

    // 5. Initialize OTEL with retry
    let otel_guard = init_otel_with_retry(config, &otlp_endpoint, 3).await
        .map_err(|e| LiveCheckError::OtlpConnection(e.to_string()))?;

    Ok(TestExecutionContext::WithLiveCheck {
        orchestrator,
        otel_guard,
    })
}

async fn init_otel_with_retry(
    config: &TestConfig,
    otlp_endpoint: &str,
    max_retries: usize,
) -> Result<OtelGuard> {
    let mut last_error = None;

    for attempt in 1..=max_retries {
        match init_otel_with_weaver(config, otlp_endpoint) {
            Ok(guard) => {
                if attempt > 1 {
                    tracing::info!("OTEL connection succeeded", attempt = attempt);
                }
                return Ok(guard);
            }
            Err(e) => {
                last_error = Some(e);
                if attempt < max_retries {
                    let backoff = Duration::from_millis(100 * (2_u64.pow(attempt as u32 - 1)));
                    tracing::warn!(
                        "OTEL connection failed, retrying",
                        attempt = attempt,
                        backoff_ms = backoff.as_millis(),
                        error = %last_error.as_ref().unwrap()
                    );
                    tokio::time::sleep(backoff).await;
                }
            }
        }
    }

    Err(last_error.unwrap())
}
```

### 3.3 Conformance Failure Handling

```rust
impl FinalTestResult {
    pub fn exit_code(&self) -> i32 {
        match (self.test_passed, self.conformance_passed) {
            (true, true) => 0,   // Success
            (true, false) => 1,  // BLOCK MERGE - schema violation
            (false, true) => 1,  // Test failure
            (false, false) => 1, // Both failed
        }
    }

    pub fn generate_report(&self, format: ReportFormat) -> Result<String> {
        match format {
            ReportFormat::Human => self.generate_human_report(),
            ReportFormat::Json => self.generate_json_report(),

        let mut report = String::new();

        report.push_str(&format!("\n{}\n", "=".repeat(60)));
        report.push_str("Test Execution Results\n");
        report.push_str(&format!("{}\n\n", "=".repeat(60)));

        report.push_str(&format!("Test: {}\n",
            if self.test_passed { "✅ PASSED" } else { "❌ FAILED" }
        ));

        // Conformance results
        if let Some(conformance) = &self.conformance_report {
            report.push_str(&format!("\n{}\n", "-".repeat(60)));
            report.push_str("Schema Conformance Results\n");
            report.push_str(&format!("{}\n\n", "-".repeat(60)));

            report.push_str(&format!("Conformance: {}\n",
                if conformance.is_conformant() { "✅ PASSED" } else { "❌ FAILED" }
            ));

            if !conformance.violations.is_empty() {
                report.push_str(&format!("\nViolations ({}):\n", conformance.violations.len()));
                for (idx, violation) in conformance.violations.iter().enumerate() {
                    report.push_str(&format!("  {}. {}\n", idx + 1, violation.message));
                    report.push_str(&format!("     Schema: {}\n", violation.schema));
                    report.push_str(&format!("     Severity: {}\n", violation.severity));
                }
            }
        }

        // Overall verdict
        report.push_str(&format!("\n{}\n", "=".repeat(60)));
        report.push_str(&format!("Overall: {}\n", self.summary()));
        report.push_str(&format!("{}\n", "=".repeat(60)));

    }
```

```rust
pub async fn execute_test_with_timeout(
    env: &CleanroomEnvironment,
    config: &TestConfig,
    context: &TestExecutionContext,
) -> Result<TestResult> {
    let timeout = Duration::from_secs(config.timeout.unwrap_or(30));

    // Wrap execution in timeout
    match tokio::time::timeout(timeout, execute_test_with_telemetry(env, config, context)).await {
        Ok(result) => result,
        Err(_) => {
            tracing::error!("Test execution timed out", timeout_secs = timeout.as_secs());

            // Force flush before reporting timeout
            if matches!(context, TestExecutionContext::WithLiveCheck { .. }) {
                let _ = flush_otel_buffers().await;
            }

            Err(CleanroomError::timeout_error(
                format!("Test execution exceeded {}s timeout", timeout.as_secs())
            ))
        }
    }
}

async fn monitor_weaver_inactivity(
    orchestrator: &LiveCheckOrchestrator<WeaverRunning>,
    inactivity_timeout: Duration,
) -> Result<()> {
    // Monitor Weaver admin API for last_telemetry timestamp
    loop {
        tokio::time::sleep(Duration::from_secs(1)).await;

        let status = orchestrator.query_status().await?;

        if let Some(last_telemetry) = status.last_telemetry_timestamp {
            let elapsed = SystemTime::now()
                .duration_since(last_telemetry)
                .unwrap_or_default();

            if elapsed > inactivity_timeout {
                tracing::warn!(
                    "Weaver inactivity timeout reached",
                    elapsed_secs = elapsed.as_secs(),
                    timeout_secs = inactivity_timeout.as_secs()
                );
                return Ok(());
            }
        }
    }
}
```

## 6. Parallel Execution Design

### 6.1 Isolation Strategies

**Strategy 1: Sequential + Single Weaver**

```
Test 1 → Test 2 → Test 3
   ↓        ↓        ↓
   └────────┴────────┴─→ Single Weaver Instance
```

**Pros:**
- Simple implementation
- Single conformance report
- Fewer resource requirements

**Cons:**
- Slow (no parallelism)
- Shared Weaver state
- One test failure affects others

---

**Strategy 2: Parallel + Multiple Weavers** (RECOMMENDED)

```
Test 1 → Weaver 1 (port 4317)
Test 2 → Weaver 2 (port 4318)
Test 3 → Weaver 3 (port 4319)
```

**Pros:**
- True isolation (per clnrm philosophy)
- Parallel execution (fast)
- Independent conformance reports
- Failures don't cascade

**Cons:**
- More resource usage
- Port coordination required

---

### 6.2 Implementation (Strategy 2)

```rust
pub async fn execute_tests_parallel(
    configs: Vec<TestConfig>,
    cli_args: &CliArgs,
) -> Result<Vec<FinalTestResult>> {
    tracing::info!("Executing {} tests in parallel", configs.len());

    // Allocate ports upfront
    let port_allocations = allocate_ports_for_tests(&configs)?;

    // Spawn test executions
    let handles: Vec<_> = configs
        .into_iter()
        .zip(port_allocations)
        .map(|(mut config, ports)| {
            // Override ports in config
            if let Some(live_check) = config.live_check.as_mut() {
                live_check.otlp_port = ports.otlp;
                live_check.admin_port = ports.admin;
            }

            tokio::spawn(async move {
                execute_single_test_isolated(config, cli_args.clone()).await
            })
        })
        .collect();

    // Wait for all tests
    let results = futures::future::join_all(handles).await;

    // Collect results
    results
        .into_iter()
        .map(|r| r.map_err(|e| CleanroomError::internal_error(e.to_string()))?)
        .collect()
}

struct PortAllocation {
    otlp: u16,
    admin: u16,
}

fn allocate_ports_for_tests(configs: &[TestConfig]) -> Result<Vec<PortAllocation>> {
    let mut allocations = Vec::new();
    let mut next_port = 4317;  // Start from standard OTLP port

    for config in configs {
        // Check if config specifies ports
        let (otlp, admin) = if let Some(live_check) = &config.live_check {
            if live_check.otlp_port != 0 && live_check.admin_port != 0 {
                // Use specified ports
                (live_check.otlp_port, live_check.admin_port)
            } else {
                // Auto-allocate
                let otlp = find_available_port(next_port)?;
                let admin = find_available_port(otlp + 1)?;
                next_port = admin + 1;
                (otlp, admin)
            }
        } else {
            // No live-check, skip
            continue;
        };

        allocations.push(PortAllocation { otlp, admin });
    }

    Ok(allocations)
}

fn find_available_port(start: u16) -> Result<u16> {
    use std::net::TcpListener;

    for port in start..=65535 {
        if TcpListener::bind(("127.0.0.1", port)).is_ok() {
            return Ok(port);
        }
    }

    Err(CleanroomError::resource_error("No available ports"))
}

    cli_args: CliArgs,

    let context = initialize_test_execution(&config, &cli_args).await?;

    let env = CleanroomEnvironment::new().await?;

    // Execute test
    let test_result = execute_test_with_telemetry(&env, &config, &context).await?;
```

## 7. Resource Management (RAII)

### 7.1 LiveCheckGuard Pattern

```rust
pub struct LiveCheckGuard {
    orchestrator: Option<LiveCheckOrchestrator<WeaverRunning>>,
    otel_guard: Option<OtelGuard>,
}

impl LiveCheckGuard {
    pub fn new(
        orchestrator: LiveCheckOrchestrator<WeaverRunning>,
        otel_guard: OtelGuard,
    ) -> Self {
        Self {
            orchestrator: Some(orchestrator),
            otel_guard: Some(otel_guard),
        }
    }

    pub async fn finalize(mut self) -> Result<ConformanceReport> {
        // 1. Flush OTEL
        if let Some(guard) = self.otel_guard.take() {
            drop(guard);
            tokio::time::sleep(Duration::from_millis(500)).await;
        }

        // 2. Stop Weaver
        if let Some(orchestrator) = self.orchestrator.take() {
            let orchestrator = orchestrator.stop_weaver().await?;
            return orchestrator.get_conformance_report();
        }

        Err(CleanroomError::internal_error("LiveCheckGuard already finalized"))
    }
}

impl Drop for LiveCheckGuard {
    fn drop(&mut self) {
        // Ensure cleanup even on panic
        if let Some(mut orchestrator) = self.orchestrator.take() {
            tracing::warn!("LiveCheckGuard dropped without finalize, forcing cleanup");

            // Block until cleanup completes (even in async context)
            tokio::task::block_in_place(move || {
                let rt = tokio::runtime::Handle::current();
                let _ = rt.block_on(async move {
                    let _ = orchestrator.stop_weaver().await;
                });
            });
        }
    }
}
```

### 7.2 Nested Resource Cleanup

```rust
pub struct TestExecutionResources {
    pub weaver_guard: Option<LiveCheckGuard>,
    pub environment: Option<CleanroomEnvironment>,
    pub temp_dirs: Vec<TempDir>,
}

impl TestExecutionResources {
    pub async fn cleanup(mut self) -> Result<Option<ConformanceReport>> {
        let mut conformance = None;

        // 1. Cleanup environment (containers)
        if let Some(env) = self.environment.take() {
            tracing::info!("Cleaning up CleanroomEnvironment");
            env.cleanup().await?;
        }

        // 2. Finalize Weaver (generates report)
        if let Some(guard) = self.weaver_guard.take() {
            tracing::info!("Finalizing Weaver live-check");
            conformance = Some(guard.finalize().await?);
        }

        // 3. Cleanup temp dirs (RAII handles this automatically)
        self.temp_dirs.clear();

        Ok(conformance)
    }
}

impl Drop for TestExecutionResources {
    fn drop(&mut self) {
        // Ensure cleanup order even on panic

        // Drop environment first (containers)
        if let Some(env) = self.environment.take() {
            tokio::task::block_in_place(move || {
                let rt = tokio::runtime::Handle::current();
                let _ = rt.block_on(env.cleanup());
            });
        }

        // Then Weaver guard
        if let Some(guard) = self.weaver_guard.take() {
            drop(guard);  // Triggers LiveCheckGuard::drop
        }

        // Temp dirs clean up automatically
    }
}
```

```rust
            tracing::error!("Test execution failed", error = %e);

            // Create failure result
            FinalTestResult {
                test_passed: false,
                conformance_passed: false,
                test_result: TestResult {
                    metadata: config.metadata.clone(),
                    step_results: vec![],
                    error: Some(e.to_string()),
                },
                conformance_report: None,
            }
        }
    }
}

#[derive(Debug, Clone)]
pub struct TestResult {
    pub metadata: TestMetadata,
    pub step_results: Vec<StepResult>,
    pub error: Option<String>,
}

impl TestResult {
    pub fn all_steps_passed(&self) -> bool {
        if self.error.is_some() {
            return false;
        }

        self.step_results.iter().all(|r| r.passed)
    }
}
```

## 11. Troubleshooting Guide

### 11.1 Common Issues

#### Issue: "Weaver binary not found"

**Symptom:**
```
Error: Weaver binary not found
Suggestion: Install with: cargo install weaver-cli
```

**Solution:**
```bash
# Install weaver
cargo install weaver-cli

# Verify installation
weaver --version

# If using Homebrew clnrm, ensure PATH includes Cargo bin
export PATH="$HOME/.cargo/bin:$PATH"
```

---

#### Issue: "Port already in use"

**Symptom:**
```
Error: Port 4317 unavailable: Address already in use
```

**Solution:**

1. **Check if Weaver already running:**
```bash
lsof -i :4317
kill <PID>
```

2. **Use auto-allocation:**
```toml
[test.live_check]
otlp_port = 0  # Auto-allocate
admin_port = 0  # Auto-allocate
```

3. **Specify different port:**
```toml
[test.live_check]
otlp_port = 5317
admin_port = 5318
```

---

#### Issue: "Schema conformance failed" (but test passed)

**Symptom:**
```
Test: ✅ PASSED
Conformance: ❌ FAILED

Overall: ❌ Test passed, but schema conformance FAILED
```

**Root Cause:** Test passed, but telemetry doesn't match schema.

**Solution:**

1. **Check conformance report for violations:**
```bash
clnrm run test.toml --format json | jq '.conformance_report.violations'
```

2. **Common violations:**
   - Missing required span attributes
   - Incorrect attribute types
   - Spans not emitted

3. **Fix code to emit conformant telemetry:**
```rust
// ❌ WRONG - missing required attribute
span.set_attribute("test.name", test_name);

// ✅ CORRECT - all required attributes
span.set_attribute("test.name", test_name);
span.set_attribute("test.hermetic", true);  // REQUIRED by schema
span.set_attribute("test.passed", result);  // REQUIRED by schema
```

---

#### Issue: "OTLP connection failed"

**Symptom:**
```
WARN: OTLP connection failed, retrying (attempt 1/3)
Error: Failed to create OTLP exporter
```

**Solution:**

1. **Check Weaver is running:**
```bash
# Query admin API
curl http://localhost:8080/status
```

2. **Verify OTLP port:**
```bash
lsof -i :4317
```

3. **Enable debug logging:**
```bash
RUST_LOG=debug clnrm run test.toml
```

4. **Force fallback to stdout:**
```toml
[test.otel]
export_stdout = true  # Bypass Weaver
```

---

#### Issue: "Weaver startup timeout"

**Symptom:**
```
Error: Timeout waiting for Weaver: Weaver startup exceeded 10s
```

**Solution:**

1. **Check system resources:**
```bash
# Check CPU/memory
top

# Check disk space
df -h
```

2. **Increase timeout:**
```rust
// In initialize_with_graceful_fallback
let orchestrator = tokio::time::timeout(
    Duration::from_secs(30),  // Increase from 10s
    orchestrator.start_weaver()
).await
```

3. **Run Weaver manually to diagnose:**
```bash
weaver registry live-check \
    --registry registry/ \
    --otlp-port 4317 \
    --admin-port 8080
```

### 11.3 Performance Troubleshooting

#### Issue: "Slow parallel execution"

**Symptom:** Parallel execution not faster than sequential.

**Diagnosis:**

```bash
# Check CPU usage during execution
top -o cpu

# Check if hitting resource limits
ulimit -a
```

**Solution:**

1. **Reduce concurrency:**
```rust
let exec_config = ParallelExecutionConfig {
    max_concurrent: 4,  // Reduce from num_cpus
    ..Default::default()
};
```

2. **Increase per-test resources:**
```toml
[test]
timeout = 60  # Increase timeout for slower machines
```

---

#### Issue: "High memory usage"

**Symptom:** System running out of memory during parallel execution.

**Solution:**

1. **Limit concurrent tests:**
```rust
let exec_config = ParallelExecutionConfig {
    max_concurrent: 2,
    per_test_memory_limit: Some(1024 * 1024 * 1024),  // 1GB
    ..Default::default()
};
```

2. **Use sequential execution:**
```bash
clnrm run tests/*.toml --no-parallel
```

## Summary

This test execution flow architecture provides:

1. **Backward Compatible**: v1.2.1 tests work without changes
2. **Opt-In Live-Check**: v1.3.0 tests enable via TOML config
3. **Graceful Fallback**: Weaver failures don't block tests
4. **True Isolation**: Parallel execution with isolated Weavers
5. **RAII Safety**: Guaranteed cleanup even on panic
6. **Comprehensive Error Handling**: Clear error messages and recovery strategies
7. **Schema-First Validation**: Weaver conformance as source of truth

**Key Design Decisions:**

- **Strategy 2 (Parallel + Multiple Weavers)** for parallel execution
- **Graceful degradation** on Weaver failures (unless `required = true`)
- **Exit code 1** if either test OR conformance fails
- **Timeout hierarchy** ensures Weaver outlives tests
- **RAII patterns** guarantee resource cleanup
